## 生成失敗

生成失敗時，WJI 會顯示白話的原因，而不是供應商的錯誤碼。總共有 33 種，以下依「你該怎麼做」分組。

### 內容被擋下

| 訊息 | 該怎麼做 |
|---|---|
| **含有真實人物** | 參考圖裡有真人，請更換 |
| **提示詞不安全** | 改用更中性的措辭 |
| **視頻／音訊／圖像內容受限** | 是*輸出*觸發了內容限制，請調整提示詞 |
| **觸發安全策略** | 可能是參考素材也可能是輸出，不確定就兩邊都改 |
| **含有禁止內容** | 圖像無法產出，請調整提示詞或參考圖 |
| **可能涉及版權** | 更換提示詞或參考素材 |
| **輸出音訊可能涉及版權** | 調整提示詞、對白或參考音頻 |

內容攔截是由模型供應商決定的，不是 WJI。換個說法通常比重試有用。

### 參考素材不對

| 訊息 | 該怎麼做 |
|---|---|
| **參考圖太小** | 最短邊必須至少 **300 px** |
| **音訊過長** | 縮短它 —— Seedance 通常需要 15 秒以內 |
| **音訊過短** | Seedance 2.0 的參考音頻通常需要至少 1.8 秒 |
| **音訊格式不支援** | 轉檔 |
| **視頻時長不符** | 檢查該模型的要求 |
| **編輯視頻時長不符** | 影片編輯需要 **4 到 30 秒**的參考片 |
| **解析度過低** | 換一支更高解析度的參考影片 |
| **缺少參考素材** | 至少加入一張參考圖或一段參考影片 |
| **參考衝突** | 語音生成不能同時用參考圖與參考音頻，請只留一種 |

### 問題出在提示詞

| 訊息 | 該怎麼做 |
|---|---|
| **缺少提示詞** | 輸入一段 |
| **提示詞過短** | 補充描述 |
| **提示詞與任務類型不符** | 生成模式的提示詞含有編輯或延長關鍵詞。請切換任務類型，或改寫 |
| **缺少編輯意圖** | 編輯模式需要 *edit*、*add*、*remove*、*replace* 這類詞 |
| **缺少延長意圖** | 延長模式需要 *extend* 或 *continue* 這類詞 |
| **任務類型不符** | 請一起檢查任務類型、畫面比例、時長與提示詞 —— 編輯與延長需要自適應比例與參考影片 |

### 什麼都沒回來

| 訊息 | 該怎麼做 |
|---|---|
| **未生成圖像** | 調整提示詞或參考素材後重試 |
| **無生成結果** | 同上 |
| **生成逾時** | 稍後重試 |

### 服務問題

| 訊息 | 該怎麼做 |
|---|---|
| **服務異常** | 暫時性的，稍後重試 |
| **配額已用盡** | 是供應商的容量，不是你的積分。稍後重試 |
| **網路異常** | 檢查連線後重試 |
| **請求無效**／**參數無效** | 檢查提示詞與參考素材 |
| **生成失敗** | 找不到更具體原因時的通用回退 |

## 其他常見問題

**「無法解析素材 ID，請先將圖片加入資產庫再拖拽」** —— 你拖了一張 WJI 認不出來的圖片。先把它存進素材庫，再從那裡拖。

**生成正在跑，我想停掉** —— 停不了，沒有取消功能。等它完成或失敗。

**換模型後參考素材不見了** —— 新模型能接受的比較少，所以最舊的被砍掉了。見[選擇模型](/zh-Hant/image-generation/models)。

**結果被風格化了但我沒要求** —— 還留著某個風格預設。它會被追加到最終提示詞但不顯示在提示詞框裡。見[撰寫提示詞](/zh-Hant/image-generation/prompts)。

**撤銷救不回我刪掉的東西** —— 請確認撤銷涵蓋什麼。建立、貼上、複製、上傳與生成結果都不可撤銷，而且切換畫布時撤銷會被清空。見[自動儲存與撤銷](/zh-Hant/infinite-canvas/autosave-and-undo)。

**我無法升級訂閱** —— 沒有升級途徑。取消、等當期結束，再訂閱你要的方案。見[訂閱](/zh-Hant/billing/subscriptions)。

**「工作區消費已達總額／本月上限」** —— 有設消費上限。見[工作區設定](/zh-Hant/workspaces/settings)。

**「您不是該組織的成員」或「組織已停用」** —— 你會被自動帶回個人空間。見[切換身份](/zh-Hant/organizations/switching-context)。

**我無法把某個成員移出組織** —— 他還是某個工作區的預算責任人，請先改指定。

**我分享出去的邀請連結需要停止作用** —— 工作區的連結可以撤銷；組織邀請不能，它會在 7 天後過期。
