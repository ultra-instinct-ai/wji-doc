---
title: "術語表"
description: "本文檔中使用的名詞。"
---

<AccordionGroup>
  <Accordion title="素材 Asset">
    任何生成或上傳的媒體 —— 圖片、影片或音頻檔案。素材屬於某則創意、會出現在畫布上，也能被當成參考素材重複使用。
  </Accordion>

  <Accordion title="素材庫">
    畫布上用 `⌘B` 開啟的面板，顯示工作區的資料夾與數據集。
  </Accordion>

  <Accordion title="素材包 Bundle">
    畫布上的一種節點，把透過連線收集到的多個媒體項目集合起來，讓一條連線能帶進很多參考素材。
  </Accordion>

  <Accordion title="畫布 Canvas">
    無限畫布應用裡的一塊板子。一個工作區可以有很多塊。
  </Accordion>

  <Accordion title="積分 Credits">
    WJI 的消費單位。見[積分如何運作](/zh-Hant/billing/how-credits-work)。
  </Accordion>

  <Accordion title="數據集 Dataset">
    一則創意與其附加媒體在儲存層的形態。畫布上的數據集節點指向其中一個。
  </Accordion>

  <Accordion title="導演欄">
    畫布底部的時間軸，用來組裝與匯出片段。
  </Accordion>

  <Accordion title="最終提示詞">
    你的提示詞經過 AI 優化後的版本，也是實際送給模型的內容。你自己的措辭會被另外保留為用戶提示詞。
  </Accordion>

  <Accordion title="生成節點">
    畫布上產出媒體的節點。參考素材透過連線抵達它。
  </Accordion>

  <Accordion title="創意 Idea">
    創意工具裡的一個條目 —— 角色、地點、道具、鏡頭、大綱或劇本 —— 帶有簡介、內容、標籤、提示詞與附加媒體。
  </Accordion>

  <Accordion title="創意工具 Idea Studio">
    收集與整理文字素材的應用。

    有些畫面把它標示為 **Creative Tools**，那是同一個應用。
  </Accordion>

  <Accordion title="節點 Node">
    放在畫布上的任何東西，共有十四種。見[節點類型](/zh-Hant/infinite-canvas/node-types)。
  </Accordion>

  <Accordion title="參考 Reference">
    餵給一次生成用來引導它的媒體或文字。在獨立生成器裡，參考素材是你逐項建立的清單；在畫布上，它們透過連線抵達。
  </Accordion>

  <Accordion title="種子 Seed">
    讓一次生成可重現的數字。`-1` 表示不指定。
  </Accordion>

  <Accordion title="片段 Segment">
    在數字主持人裡，一段對白及其專屬的配音與影片。
  </Accordion>

  <Accordion title="分鏡模式">
    一種生成模式，把一組鏡頭或角度產在同一張圖上。
  </Accordion>

  <Accordion title="任務類型 Task mode">
    在 Seedance 影片模型上，指這一次是生成、編輯還是延長。提示詞的措辭必須與模式相符。
  </Accordion>

  <Accordion title="工作區 Workspace">
    一個專案的容器 —— 創意、素材、畫布、成員與設定。
  </Accordion>
</AccordionGroup>
