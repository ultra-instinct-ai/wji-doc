參考素材是讓一個角色在上百個鏡頭裡看起來還是同一個人的方法。對一致性來說，它比提示詞的措辭重要得多。

## 六種加入方式

<Steps>
  <Step title="選檔案">
    點擊瀏覽，可以多選。
  </Step>
  <Step title="拖放或貼上">
    把檔案放到提示詞框上，或直接貼上。這個途徑只接受圖片。
  </Step>
  <Step title="從數據集">
    從你工作區的創意裡選，會依角色、地點、服裝、道具與風格分組。
  </Step>
  <Step title="從 IP 資產">
    虛擬人角色資產有獨立的頁籤。
  </Step>
  <Step title="從生成結果">
    把滑鼠移到任何一筆歷史結果上，直接把它加為參考素材。
  </Step>
  <Step title="最近使用">
    你最近用過的六個參考素材，一鍵可及。
  </Step>
</Steps>

## 參考類型

每個參考素材都有類型，點卡片即可設定。

| 類型 | 用於 |
|---|---|
| **角色** | 人物 |
| **場景** | 地點與外景 |
| **服裝** | 衣著 |
| **道具** | 物件 |
| **風格** | 視覺調性 |
| **布局** | 構圖 |
| **其他** | 其餘一切 |

從數據集拉進來的參考素材會自動繼承類型，這是把創意的類型填準的另一個好理由。

參考素材也可以命名。預設是 `image1`、`image2` 等，這也是你在提示詞裡用 `@` 引用的名字。

## 上限

**參考素材的數量上限由模型決定，不是 WJI 決定。** 超過時，新的會加在最後，最舊的會從最前面被砍掉。

Vertex 協定的模型單張參考圖上限是 20 MB。

## 參考影片與參考音頻

在影片模式下，你還可以加入參考影片與參考音頻。

| 限制 | 數值 |
|---|---|
| 格式 | MP4 或 MOV |
| 預設上限 | 3 段 |
| 時長 | 2–15 秒，部分模型可到 30 秒 |
| 檔案大小 | 15 秒以內 50 MB，15–30 秒 200 MB |
| 尺寸 | 每邊 300–6000 px |
| 長寬比 | 0.4 到 2.5 之間 |
| 像素 | 最高 1920×1080 |

<Warning>
  如果 WJI 讀不出影片的時長，不論它實際多長，大小上限都會降到 50 MB。
</Warning>

## 權重

只有一個**參考圖權重**滑桿，套用到所有參考素材，不是每張一個。Midjourney 家族的模型另外在模型專屬設定裡提供圖片權重與風格參考權重。

## 在畫布上

無限畫布不用上傳清單。參考素材來自**連線** —— 你把圖片、影片或音頻節點接到生成節點上，它就成為參考。見[連線與參考](/zh-Hant/infinite-canvas/connections-and-references)。
