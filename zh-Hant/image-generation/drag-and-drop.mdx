title: "拖放操作"
description: "WJI 裡所有的拖曳互動，從桌面檔案到畫布節點到參考槽位。"
---

拖曳是 WJI 裡搬動素材的主要方式。這一頁列出你能拖什麼、能放到哪、以及會發生什麼。

## 放到畫布上

| 拖這個 | 結果 |
|---|---|
| 任何地方來的素材（素材庫、歷史記錄、側欄、網格） | 在放下的位置產生一個媒體節點 |
| 素材庫的數據集卡片 | 一個數據集參考節點 |
| 桌面來的圖片、影片或音頻檔 | 每個檔案一個媒體節點 |
| CSV 或表格檔 | 一個表格節點 —— 多個檔案會往下堆疊 |
| Markdown 或文字文件 | 一個文字節點 |

<Note>
  如果素材只有 URL 還沒有 ID，WJI 會先解析。解析失敗時會提示你先把圖片加入資產庫再拖。
</Note>

## 在畫布上按住 Alt 拖曳

按住 **Alt** 會改變拖曳的意義，而且依你抓的東西不同，它有四種完全不同的意義。

| Alt 拖曳 | 放到 | 結果 |
|---|---|---|
| 媒體或文字節點 | **數據集節點** | 歸檔進那個數據集 |
| 媒體或文字節點 | **素材庫的數據集** | 歸檔進去 |
| 媒體或文字節點 | **素材庫卡片之間的縫隙** | 在該位置建立一個新數據集 |
| 媒體節點 | **導演欄** | 新增一個片段，或設為該片段的主媒體 |
| **數據集節點內的縮圖** | 另一個數據集節點 | 在數據集之間移動素材 |
| **數據集節點內的縮圖** | 畫布空白處 | 用它建立一個媒體節點 |
| **節點本身** | 畫布上任何地方 | 複製它 |
| **連接手柄** | 多個節點 | 一對一扇出，每個來源各建一個新節點 |

如果你放到沒有意義的地方，WJI 會告訴你有效的目標在哪，而不是默默失敗。

## 在數據集之間搬素材

| 從 | 到 | 結果 |
|---|---|---|
| 側欄數據集的縮圖 | 中欄內容區 | 移進當前數據集 |
| 中欄網格卡片 | 側欄的數據集卡片 | 移進那個數據集 |
| 任何素材 | 側欄空白處 | 開啟新建數據集對話框 |
| 任何素材或檔案 | 素材庫卡片之間的縫隙 | 在該位置建立新數據集 |

<Warning>
  這些是**移動**，不是複製。素材會從來源數據集移除、加到目標，兩邊都會存檔。側欄在拖曳時會標示為複製操作，但實際行為是移動 —— 如果你要兩邊都有，請用素材選單的**複製到**。
</Warning>

把已經在目標裡的素材放進去，系統會告訴你，並且不做任何改動。

## 放到參考槽位

| 目標 | 接受 |
|---|---|
| 統一參考區 | 檔案或素材，會自動分派到圖片、影片或音頻 |
| 參考圖清單 | 圖片檔或圖片素材 |
| 參考影片清單 | 影片檔或影片素材 |
| 參考音頻清單 | 音頻檔或音頻素材 |
| 首幀／尾幀槽位 | 圖片檔或圖片素材 |

從數據集拖出來的素材會帶著它的數據集名稱與類型，所以參考素材一到就已經命名好、也已經標成角色、場景等類型。

<Note>
  在畫布上，首尾幀**不是**用拖的。它們是透過連線指派的。見[連線與參考](/zh-Hant/infinite-canvas/connections-and-references)。
</Note>

## 從桌面拖檔案

除了畫布，以下區域也直接接受檔案：

- 數據集內容區 —— 圖片、影片與音頻
- 素材庫，會用你放下的東西建立一個新數據集
- 上面列出的每一個參考槽位

數據集內容區也接受**貼上**的檔案。

<Note>
  創意詳情頁有上傳按鈕，但它不是一個拖放目標。
</Note>

## 拖曳調整面板寬度

側欄與內容區的右緣都有拖曳把手。

| 面板 | 範圍 |
|---|---|
| 側欄 | 240–480 px |
| 內容區 | 300–480 px |

寬度會被記住。
