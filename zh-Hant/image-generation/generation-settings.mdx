## 最常見的設定

| 設定 | 作用 |
| --- | --- |
| **畫面比例** | 一組比例縮圖。只有模型支援的比例會出現 |
| **生成數量** | 一次跑幾張。範圍由模型決定 |
| **參考圖權重** | 參考素材對結果的影響強度 |
| **Omni 權重** | 在支援的模型上 |
| **風格權重** | 在支援的模型上 |
| **Stylize** | 通常是 0–1000，Midjourney 家族才有 |
| **風格提示詞** | 開啟風格選擇器 |
| **時長** | 只有影片模式有 |

有些模型的比例選項裡有**自動匹配**，它會配合輸入圖片而不是硬套一個形狀。

## 種子

當模型有種子時，它會以一個標籤出現在主表單上。`-1` 表示不指定，由模型自己決定。

種子是讓結果可重現的關鍵。如果你拿到一張差一點就對的圖，從歷史卡片記下它的種子（點種子標籤即可複製），然後一邊沿用它一邊調整提示詞。

## 模型專屬設定

彈窗裡其餘的東西都是依模型定義動態產生的，換模型就會變。每個控制項都有 tooltip 說明它的作用。

常見的有：

- **解析度**與**輸出格式**
- **chaos** —— 多樣性，0 到 100
- **quality**
- Midjourney 家族的**圖片權重**與**風格參考權重**
- **Raw 模式**與 **HD**

## 生成數量與分鏡

選了分鏡布局會強制把生成數量設為 1，因為那個網格**本身就是**唯一的輸出。見[分鏡模式](/zh-Hant/image-generation/storyboard-mode)。
