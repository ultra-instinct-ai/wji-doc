## 把結果歸檔

<Frame caption="選擇目標數據集">
  <img src="/images/image-generation/move-to-dialog-01.png" alt="移動或複製素材時，用來選擇目標數據集的樹狀選擇器" />
</Frame>

| 操作 | 位置 | 作用 |
|---|---|---|
| **保存到 Idea** | 結果選單，僅工作區內 | 把素材掛到當前創意上 |
| **設為 Idea 封面** | 結果選單 | 設為該創意的封面圖 |
| **從圖片創建創意** | 結果選單 | 用這張圖建立一則新創意 |
| **保存到素材庫** | 畫布節點工具列 | 把畫布節點的素材歸進某個數據集 |
| **移動到** | 素材選單 | 在數據集之間移動 —— 會從來源移除 |
| **複製到** | 素材選單 | 加到目標並保留原本的 |

**移動到**與**複製到**會開啟樹狀選擇器讓你選目標數據集。兩者都支援多選，並會回報移動或複製了幾筆。

<Note>
  如果被移動的素材是來源數據集的封面，系統會自動把另一張圖升為封面。
</Note>

## 預覽

<Frame caption="素材預覽對話框">
  <img src="/images/image-generation/asset-preview-01.png" alt="素材預覽對話框，含圖片、顯示生成詳情的資訊面板，以及評論頁籤" />
</Frame>

有六套不同的預覽介面，各自適合不同的工作。

| 預覽 | 從哪裡開 | 適合 |
|---|---|---|
| **輕量燈箱** | 點擊圖片 | 快速看、方向鍵翻頁、縮放 |
| **素材預覽對話框** | 眼睛圖示、縮圖、歷史記錄 | 什麼都能做 —— 資訊、生成詳情、評論、再次生成 |
| **數據集預覽** | 畫布數據集節點 | 審閱與重排一組素材，就地編輯欄位 |
| **素材包預覽** | 畫布素材包節點 | 啟用、停用、重新命名與重排成員 |
| **全景查看器** | 全景節點 | 360° 觀看 |
| **圖庫檢視** | 創意詳情 | 全螢幕瀏覽，可用鍵盤導覽 |

<Warning>
  燈箱只用於圖片。影片刻意不走它，因為點擊會變成觸發下載而不是播放。
</Warning>

**素材預覽對話框**是最值得熟悉的一個。它承載基本資訊、檔案詳情、完整生成詳情、兩份提示詞（各附複製按鈕）、用到的參考素材、標籤、評論、按讚、就地改名，以及**用於再次生成**。

## 排序

有九種清單支援拖曳排序，各自存在不同的地方：

| 清單 | 存成 |
|---|---|
| 側欄的數據集 | 該資料夾的子項順序 |
| 素材庫的數據集 | 上層的子項順序 |
| 數據集內的素材 | 該數據集的圖片順序 |
| 素材包內的素材 | 該素材包節點的素材順序 |
| 畫布生成節點的參考 | 該節點連線的順序 |
| 生成器裡的參考卡 | 送出的參考陣列 |
| 導演欄片段 | 時間軸 |
| 分鏡建立器的鏡頭 | 建立器的選取清單 |

<Note>
  在生成器裡，只有**同一媒體類型**的參考素材彼此之間才能互換順序。
</Note>

## 重新命名、標籤與刪除

在素材預覽對話框頂部就地改名，或在它的資訊面板裡改。標籤也在同一個面板 —— 輸入後按 Enter。

刪除可從素材選單、側欄縮圖的浮層，或創意詳情檢視。刪除單一素材會要求確認；刪除多選會告訴你將刪掉幾筆。

## 評論與按讚

兩者都在素材預覽對話框裡，也都取決於工作區是否允許。滑過按讚會顯示誰按過、什麼時候按的。見[查看者權限](/zh-Hant/workspaces/viewer-access)。

## AI 描述

**描述圖片**、**描述影片**或**描述音頻**會讓 AI 讀過素材並回傳一段文字描述，你可以複製它。在畫布上，同一個功能會用結果建立一個文字節點。
