## 模型能力長什麼樣

WJI 不用標籤列出能力，而是**換模型時控制項會跟著變**。沒出現的設定，就是那個模型不支援。

換模型也可能改動你現有的設定：

| 如果新模型…… | WJI 就…… |
| --- | --- |
| 不支援你的畫面比例 | 把你移到它支援的最接近比例 |
| 能接受的參考圖比較少 | **從清單最前面砍掉多出來的** |
| 完全不接受參考素材 | 提示你當前模型不支援參考圖 |
| 時長限制不同 | 套用它自己的預設時長 |

<Warning>
  參考素材被砍這件事值得記住。如果你有五張參考圖、換到一個只吃三張的模型，你留下的是**最後三張** —— 最早加的那些會被移除。
</Warning>

換模型也會清空最終提示詞並重新優化。

## 畫面比例的回退

在工作區裡，如果新模型不支援你當前的比例，WJI 會先試工作區的預設比例，都不行才退到模型的第一個支援比例。

## 模型專屬設定

模型獨有的東西會以動態表單出現在設定彈窗裡。常見的例如：

- **種子 Seed** —— `-1` 表示不指定
- **解析度**或輸出尺寸
- Midjourney 家族的 **chaos**、**quality**、**stylize**、**Raw 模式**、**HD**
- Seedance 影片模型的**任務類型**、**自動時長**、**輸出格式**
- 語音模型的**發音人**、**語速**、**音調**、**音量**

<Note>
  WJI 沒有負面提示詞欄位。請描述你要什麼，而不是你不要什麼。
</Note>
