## 選取

| 動作 | 怎麼做 |
|---|---|
| 選一個 | 點它 |
| 加選 | `Shift` + 點擊，或 `⌘` + 點擊 |
| 框選 | 在空白處拖曳。**碰到**框的都會被選中，不只是被完全框住的 |
| 框選加選 | `Shift` + 拖曳 |
| 全選 | `⌘A` |
| 依顏色標籤選取 | `Shift` + `1`–`8` |
| 取消選取 | `Esc` |

<Warning>
  **全選與依標籤選取的上限都是 50 個節點。** 在大畫布上你不會拿到全部。若正在套用顏色標籤篩選，全選只會選中帶有該標籤的節點。
</Warning>

未選中的節點是在滑鼠**放開**時才被選中，不是按下時，所以開始拖曳不會觸發它的面板。

## 移動與複製

- 拖曳即移動
- **Alt + 拖曳**會複製 —— 原本的節點留在原地
- `⌘D` 原地複製選取項
- `⌘C` 與 `⌘V` 複製與貼上，**連同被複製節點之間的連線一起**

## 改大小

支援的節點右下角有拉柄。最小尺寸各異：分組 120×80、文本 120×60、YouTube 240×135。箭頭是拖任一端點來調整。

文字節點還可以用 `[` 與 `]` 等比縮放視窗。多選時它們之間的間距會被保留。

## 重新命名

**雙擊節點上方的名稱標籤。** Enter 提交，`Esc` 取消。

## 多選工具列

選中兩個以上節點時，底部會滑出一條工具列：

| 按鈕 | 作用 |
|---|---|
| **顏色標籤** | 對所有選取項套用標籤 |
| **對齊** | 水平、垂直或自動 |
| **群組** | 把選取項包進一個分組節點 |
| **添加引用** | 進入從畫布挑選的模式 |
| **模型設置** | 對每個同類型的生成節點套用模型設定 |
| **優化提示詞** | 優化每一個選中的提示詞 |
| **批量提交** | 開啟審閱對話框，列出每個節點的提示詞、引用、模型與參數，然後一起送出 |
| **下載選中** | 單檔，或以畫布命名的 ZIP |

對查看者而言只剩**下載選中**。

## 對齊與群組

對齊是一次性的動作，不是即時輔助線：

| 動作 | 快捷鍵 |
|---|---|
| 水平對齊 | `H` |
| 垂直對齊 | `V` |
| 自動對齊 | `⌘K` |

分組節點會在選取項外留 40 px 的邊距。拖曳分組會帶動任何碰到它的節點。

<Note>
  選中兩個以上節點時，`V` 是垂直對齊，而不是「新建影片節點」。
</Note>

## 顏色標籤

八種顏色，每一種都能為整張畫布命名。

| 動作 | 快捷鍵 |
|---|---|
| 對選取項切換標籤 | `⌘1`–`⌘8` |
| 清除標籤 | `⌘0` |
| 選取帶某標籤的節點 | `Shift 1`–`Shift 8` |
| 依標籤篩選畫布 | `⌥1`–`⌥8` |
| 清除篩選 | `⌥0` |

標籤驅動小地圖的顏色、頂欄的篩選、依標籤批次下載，以及查看者被允許看到什麼。

<Tip>
  請為標籤命名。「已定案」「待修改」「可給客戶看」能把顏色編碼的習慣變成整個團隊都讀得懂的東西 —— 查看者權限裡的可見標籤設定，這時才真的替你做事。
</Tip>

## 做不到的事

沒有節點鎖定，也沒有置頂或置底。層級是固定的：分組節點永遠繪製在其他所有東西的後面。
