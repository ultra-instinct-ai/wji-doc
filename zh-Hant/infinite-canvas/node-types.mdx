## 內容節點

| 節點 | 放什麼 | 值得注意的操作 |
|---|---|---|
| **文本** | Markdown | 雙擊編輯、AI 助手、匯入文件、下載成 Markdown／純文字／Word、用 `[` `]` 縮放視窗 |
| **表格** | 帶欄位映射的列與欄 | 編輯表格、AI 助手、映射哪一欄是文字、哪一欄是提示詞、重新上傳 |
| **YouTube** | 內嵌的 YouTube 連結 | 貼上網址即可建立。AI 助手能產出摘要、改寫與腳本，成為文字節點 |
| **數據集** | 一個工作區數據集 | 在素材視圖與內容視圖之間切換、從它創建圖片或影片、上傳、下載、分鏡工具 |
| **素材包** | 透過連線收集的多個媒體項目 | 下載、預覽、分鏡工具。成員可停用、重排、改名、移除 |

## 結構與標註

| 節點 | 用途 |
|---|---|
| **分組** | 一個永遠繪製在最底層的視覺容器。拖曳它會帶動它碰到的節點。不能連線 |
| **標題** | 大字，框會依字號自動調整 |
| **備註** | 便利貼 |
| **待辦** | 可新增、刪除與勾選的清單 |
| **箭頭** | 兩個可拖曳的端點 |

後四種統稱**標註**。它們共用前景與背景色控制項，而且可以在不給編輯權的情況下允許查看者新增。見[查看者權限](/zh-Hant/workspaces/viewer-access)。

<Note>
  分組節點永遠繪製在其他節點下方，而且不能參與連線。它們用來整理空間，不會把語意帶進生成。
</Note>
