## 六個入口

<Frame caption="創建面板">
  ![創建面板，列出可放上畫布的每一種節點類型](/images/Screenshot-2026-09-02-at-15.26.06.png)
</Frame>

<Steps>
  <Step title="雙擊空白處">
    在該位置開啟建立選單。空白畫布上的提示就是這麼寫的。
  </Step>
  <Step title="右鍵空白處">
    提供**上傳**、**創建節點**與**貼上**。
  </Step>
  <Step title="創建按鈕">
    膠囊工具列的第一個圖示。開啟建立面板，點擊類型會把它放在你視野的中心。
  </Step>
  <Step title="從連接手柄拖出">
    把節點的 `+` 手柄拖到空白處放開。跳出的選單會建立一個**已經連好線**的新節點。
  </Step>
  <Step title="鍵盤">
    `I`、`V`、`A` 會在指標位置建立圖片、影片與音頻生成節點。如果有選中的東西，新節點會自動連上去。
  </Step>
  <Step title="拖放、貼上或上傳">
    見下方的**把檔案放上畫布**。
  </Step>
</Steps>

## 建立選單有什麼

<Frame caption="雙擊空白處開啟的建立選單">
  ![畫布上的選單，分隔線上方是媒體節點類型，下方是標註子選單](/images/9月1日\(29\).gif)
</Frame>

完整選單列出媒體類型 —— 文本、表格、圖片、全景、視頻、音頻、數據集、素材包、分組 —— 接著是一條分隔線，然後是**標註**子選單，裡面有標題、備註、待辦與箭頭。

從 `+` 手柄拖出時清單會短一些，因為不是每種東西都適合當連線的目標。數據集與分組會被排除。如果來源是有素材的圖片節點，會多出全景。另有一個**更多**子選單，包含描述、分鏡、深度視頻、視頻超分、圖轉草稿與角色設定表。

## 把檔案放上畫布

你不需要先把檔案上傳到別的地方。直接丟到板子上，WJI 會自己判斷它是什麼。

### 四種方式

<Steps>
  <Step title="從桌面拖進來">
    把一個或多個檔案放到板子上任何位置。每個檔案會在放下的地方各自成為一個節點。
  </Step>
  <Step title="貼上">
    `⌘V` 接受剪貼簿裡的圖片、表格檔、表格純文字，或一般文字。
  </Step>
  <Step title="右鍵空白處">
    選**上傳**並挑選檔案。
  </Step>
  <Step title="節點自己的上傳按鈕">
    圖片、視頻、音頻與數據集節點的工具列各有一個上傳控制項，用來把檔案放進已經存在的節點。
  </Step>
</Steps>

### 各種檔案會變成什麼

| 放這個 | 得到 |
| --- | --- |
| 圖片檔 | **圖片**節點 |
| 影片檔 —— `mp4`、`mov`、`webm`、`m4v`、`mkv`、`avi` | **視頻**節點 |
| 音檔 —— `mp3`、`wav`、`m4a`、`aac`、`ogg`、`flac`、`opus`、`weba`、`webm` | **音頻**節點 |
| CSV 或表格檔 | **表格**節點。一次多個會往下堆疊 |
| Markdown 或文字文件 | **文本**節點 |
| 以文字貼上的 YouTube 連結 | **YouTube** 節點 |

圖片是依類型而非副檔名辨識的，所以只要你的瀏覽器把它當成圖片就可以。

<Warning>
  上傳上限是圖片、音頻與文件 **25 MB**，影片 **200 MB**。完整限制（包含參考影片那些更嚴格的規定）見[支援的檔案類型](/zh-Hant/reference/supported-file-types)。
</Warning>

拖曳的如果是既有的**素材**而不是檔案 —— 來自素材庫、生成歷史，或應用的其他地方 —— 同樣會建立節點。那些以及其他所有拖曳手勢，都收錄在[拖放操作](/zh-Hant/image-generation/drag-and-drop)。

## 貼上

在畫布上按 `⌘V` 會依序處理幾種內容：

1. **圖片檔或圖片 URL** → 上傳並放成圖片節點
2. **表格檔** → 表格節點
3. **表格純文字**（TSV 或 CSV）→ 表格節點
4. **純文字** → 若是 YouTube 連結則建立 YouTube 節點，否則建立文字節點
5. **你先前複製的節點** → 連同它們之間的連線一起貼上

如果你移動過滑鼠，貼上會落在指標位置，否則會相對上一次貼上稍微偏移。

## 表格的每一列都能變成節點

從**表格節點**拖出連線去建立非表格節點時，會**每一列各建立一個已連線的節點**。這是把一份鏡頭表變成一組生成節點最快的方法。

<Tip>
  把鏡頭表貼成表格，映射好放提示詞的那一欄，然後從表格拖出去。每一列都會變成自己的生成節點，線已經接好、提示詞也已經帶上。
</Tip>
