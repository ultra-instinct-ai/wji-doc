## 節點

| 快捷鍵 | 動作 |
| --- | --- |
| `I` | 新建圖片生成節點 |
| `V` | 新建影片生成節點 |
| `A` | 新建音頻生成節點 |
| `/` | 從提示詞預設建立文字節點 |
| `⌥` + `I` / `V` / `A` | 對每個選中節點一對一生成 |
| 雙擊空白處 | 建立選單 |
| 雙擊文字節點 | 編輯它 |
| `⌘ ↵` | 提交文字編輯 |
| `⌥` + 拖曳 | 複製節點，或拖進數據集 |
| 拖 `+` | 從多選建立連線 |
| `⌥` + 拖 `+` | 從多選扇出 |

## 編輯

| 快捷鍵 | 動作 |
| --- | --- |
| `⌘Z` | 復原 |
| `⌘⇧Z`（Windows `Ctrl+Y`） | 重做 |
| `⌘C` | 複製 |
| `⌘V` | 貼上 |
| `⌘D` | 複製副本 |
| `⌫` 或 `Del` | 刪除 |
| `Esc` | 取消或清除選取 |
| `⌘A` | 全選，上限 50 個節點 |
| `⌘G` | 群組 |

## 視口

| 快捷鍵 | 動作 |
| --- | --- |
| `Space` + 拖曳 | 平移 |
| 中鍵拖曳 | 平移 |
| 滾輪 | 垂直平移；`Shift` + 滾輪水平平移 |
| `⌘` + 滾輪 | 縮放 |
| `⌘ =` | 放大 |
| `⌘ -` | 縮小 |
| `⇧Z` | 適應全部節點 |
| `Tab` 或 `Z` | 縮放至選中節點 |
| `H` | 水平對齊 |
| `V` | 垂直對齊（選中兩個以上時） |
| `⌘K` | 自動對齊 |
| `[` | 縮小文字節點視窗 |
| `]` | 放大文字節點視窗 |
| `⇧` + 點擊或拖曳 | 加選 |

## 標籤與面板

| 快捷鍵 | 動作 |
| --- | --- |
| `⌘B` | 素材庫 |
| `⌥` + ``` | 切換選擇參考模式 |
| `⌘1`–`⌘8` | 對選取項切換顏色標籤 |
| `⌘0` | 清除選取項的標籤 |
| `⇧1`–`⇧8` | 選取帶該標籤的節點，上限 50 個 |
| `⌥1`–`⌥8` | 依標籤篩選，或把帶該標籤的節點連到選中的生成節點 |
| `⌥0` | 清除標籤篩選 |

## 導演欄

以下在導演欄取得焦點時生效。

| 快捷鍵 | 動作 |
| --- | --- |
| `Space` | 播放／暫停 |
| `←` `→` | 上一個／下一個 |
| `↑` | 選擇主媒體 |
| `S` | 分割 |
| `Delete` | 刪除片段 |
| `⌘Z` / `⇧⌘Z` | 復原／重做 |
| `⌘` + 滾輪 | 縮放時間軸 |

<Note>
  `V` 是刻意一鍵兩用的。沒有選取時它建立影片節點；選中兩個以上節點時它做垂直對齊。
</Note>
