**導演欄**從膠囊工具列開啟，橫在畫布底部。它是一條把片段排順序的時間軸。

<Frame caption="橫在畫布底部的導演欄">
  <img src="/images/infinite-canvas/director-bar-01.png" alt="導演欄時間軸上依序排著數個片段，並有播放控制項與匯出選單" />
</Frame>

## 把素材放進去

- 把圖片或影片**拖**到時間軸上
- 從畫布 **Alt + 拖**一個媒體節點到欄上 —— 它會成為一個片段，或設為既有片段的主媒體
- 從影片節點的工具列選**加入導演欄**
- 放置區的提示：把圖片或影片拖放到此處

## 模式

時間軸可以在影片、圖片或混合模式下工作。圖片會使用你設定的**預設圖片時長**（以秒為單位）。

## 編輯

| 動作 | 怎麼做 |
|---|---|
| 播放／暫停 | `Space` |
| 上一個／下一個 | `←` `→` |
| 選擇主媒體 | `↑`，再用方向鍵瀏覽，`Enter` 確認，`Esc` 關閉 |
| 分割 | `S` |
| 刪除片段 | `Delete`，附確認 |
| 復原／重做 | `⌘Z` / `⇧⌘Z` |
| 縮放時間軸 | `⌘` + 滾輪 |
| 平移 | 拖曳時間軸 |

其他控制項：靜音、循環、**吸附**、顯示全部、替換媒體、清除媒體，以及新增空白數據集。

<Note>
  這裡的吸附是片段之間的時間軸吸附，與畫布上的節點對齊無關 —— 畫布完全沒有吸附。
</Note>

## 匯出

<Frame caption="匯出選單">
  <img src="/images/infinite-canvas/director-export-01.png" alt="匯出選單提供匯出影片、匯出 NLE 專案與下載全部媒體" />
</Frame>

三個選項：

<Columns cols={3}>
  <Card title="匯出影片" icon="film">
    把時間軸算成一支 MP4。
  </Card>
  <Card title="匯出專案 (NLE)" icon="file-zipper">
    一個 ZIP，內含 `timeline.otio`、`timeline.edl`、`media/` 資料夾與 `manifest.json` —— 用來把剪輯帶進專業剪輯軟體繼續做。
  </Card>
  <Card title="下載全部媒體" icon="download">
    每個片段的來源檔案。
  </Card>
</Columns>

當畫布已經完成它的任務、剪輯要進 Premiere、Resolve 或 Final Cut 時，NLE 匯出就是你要的。OTIO 與 EDL 檔案帶著剪輯決定，media 資料夾帶著素材。

<Tip>
  在投入放大或重生成鏡頭之前，先用導演欄確認這個序列讀得通。粗剪的片段排在正確順序上，比一顆打磨過的鏡頭更能告訴你這場戲成不成立。
</Tip>
