**無限畫布**是一片你放置節點並把它們接起來的板子。當一張圖不再是工作單位時 —— 當你在建構一個序列、要讓一組鏡頭保持一致、或要組一個剪輯時 —— 就該用這個應用。

<Frame caption="接好線的畫布">
  ![無限畫布上，圖片與文字節點接進一個生成節點](/images/infinite-canvas/overview-01.png)
</Frame>

## 唯一重要的概念

**連線不是裝飾，它是上下文抵達 AI 的方式。**

把圖片節點接進生成節點，那張圖就成為參考素材。接一個文字節點進去，它的內容會被加到提示詞前面。接一個數據集進去，它的成員會被展開。

想通這一點，畫布其餘的部分就順了。請先讀[連線與參考](/zh-Hant/infinite-canvas/connections-and-references)，再看別的。

## 螢幕上有什麼

<Frame caption="畫布的介面元件：膠囊工具列、頂欄與視口控制列">
  ![畫布上標出左側膠囊工具列、上方頂欄與左下視口控制列](/images/WJI-工作區的無限畫布-2.png)
</Frame>

| 區域 | 內容 |
| --- | --- |
| 左側**膠囊工具列** | 創建、素材庫、生成歷史、導演欄、設置、快捷鍵 |
| **頂欄** | 顏色標籤篩選、畫布切換器、搜尋、畫布設置 |
| 左下**視口控制列** | 撤回／前進、縮放、適應、小地圖、效能模式 |
| 底部**導演欄** | 組裝片段的時間軸 —— 從膠囊工具列開啟 |
| 左上**儲存狀態** | 待保存、保存中、已保存或保存失敗 |

開啟畫布會讓工作區的左側面板收成窄欄，而且在這裡時它會一直保持收合。

## Alt 會改變拖曳的意義

Alt —— 在 Mac 上是 **Option** —— 是值得早點學會的修飾鍵。不按它時，拖曳是**移動**；按住它，同一個手勢會變成**歸檔、複製或扇出**。它的行為隨你抓的東西而不同，所以值得把所有情況放在一起看。

### Alt + 拖曳

| 按住 Alt 拖 | 放到 | 結果 |
| --- | --- | --- |
| 一個節點 | 畫布上任何地方 | **複製**它 —— 原本的留在原地 |
| 節點的 `+` 手柄 | 多個選中的節點 | **扇出** —— 每個來源各一個新節點，一對一 |
| 媒體或文字節點 | **數據集節點** | 歸檔進那個數據集 |
| 媒體或文字節點 | **素材庫的數據集** | 歸檔進去 |
| 媒體或文字節點 | **素材庫卡片之間的縫隙** | 在該位置建立新數據集 |
| 媒體節點 | **導演欄** | 新增片段，或設為既有片段的主媒體 |
| **數據集節點內的縮圖** | 另一個數據集節點 | 在數據集之間移動素材 |
| **數據集節點內的縮圖** | 畫布空白處 | 用它建立媒體節點 |
| **素材庫**裡的素材 | 畫布 | 用它建立節點 |

<Note>
  如果你放到 Alt 沒有意義的地方，WJI 會告訴你有效的目標在哪，而不是默默失敗。
</Note>

### Alt + 按鍵

| 快捷鍵 | 作用 |
| --- | --- |
| `⌥` + `I` / `V` / `A` | 對**每一個**選中的節點各生成一個，而不是只生成一個 |
| `⌥` + `1`–`8` | 依標籤篩選 —— 若已選中生成節點，則把帶該標籤的節點全部連上去 |
| `⌥` + `0` | 清除標籤篩選 |
| `⌥` + ``` | 切換選擇參考模式 |

只要按住 Alt 會改變下一次拖曳的行為，多選工具列就會顯示一個 `⌥` 徽章，你不必記住哪些手勢有兩種意義。
