**創意工具**是專案裡「文字」那一面的所在。你在這裡收集故事的組成材料 —— 誰在裡面、發生在哪裡、畫面裡有什麼 —— 而你寫下的一切，其他應用都能當成參考取用。

<Note>
  有些畫面仍把這個應用標示為 **Creative Tools**，那是同一個應用。
</Note>

## 資料夾

每個工作區的創意工具都預先建好六個資料夾：

| 資料夾 | 放什麼 |
|---|---|
| **故事** | 大綱、前提、完整劇本 |
| **角色** | 人物，含描述與參考圖 |
| **地點** | 場景與外景 |
| **道具** | 出現在畫面裡的物件 |
| **分鏡** | 單一鏡頭，含運鏡與構圖說明 |
| **其他** | 放不進上面任何一類的東西 |

這六個是系統資料夾。你不能重新命名、刪除或複製它們，但可以在裡面建立自己的子資料夾。

## 一則創意包含什麼

每則創意是一張卡片，包含：

- **類型** —— 大綱、劇本、角色、地點、道具、服裝、場景、鏡頭或其他
- **簡介**，這是必填的
- **詳細內容**，支援 Markdown
- **標籤**
- **圖像提示詞**與**影片提示詞**
- 掛在它底下的**圖片與影片**
- 自由格式的**額外資訊**

簡介比它看起來重要。當這則創意被當成參考用於生成時，AI 讀的就是簡介。

## 創意接下來會去哪

創意不是最終成品。從一則創意，你可以：

- 在[創意工具圖片生成](/zh-Hant/image-generation/overview)裡以它為參考生成圖片與影片
- 把它拖到[畫布](/zh-Hant/infinite-canvas/overview)上成為數據集節點
- 把它餵給工作區 AI 聊天當作上下文

在詳情檢視裡點創意的頭像，會直接跳進創意工具圖片生成，並已選好這則創意。
