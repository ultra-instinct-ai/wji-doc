左側面板的檔案樹是你整理東西的地方，而它最有力的部分在右鍵選單。

## 一般操作

對任何創意或資料夾按右鍵：

| 操作 | 適用對象 | 說明 |
|---|---|---|
| **添加到聊天** | 創意 | 把創意送進工作區 AI 聊天當作上下文 |
| **新增〈類型〉** | 資料夾 | 文案會隨資料夾變化 —— 在「角色」裡是「新增角色」 |
| **新建文件夾** | 資料夾 | 建立子資料夾 |
| **複製** | 創意 | 產生帶「副本」後綴的複本 |
| **重命名** | 兩者 | |
| **刪除** | 兩者 | |
| **下載資源** | 兩者 | 一個保留資料夾結構的 ZIP |

六個系統資料夾 —— 故事、角色、地點、道具、分鏡、其他 —— 不能重新命名、刪除或複製。

<Note>
  檔案樹沒有搜尋框。請用資料夾與標籤讓東西找得到。
</Note>

## AI 捷徑

<Frame caption="在劇本上右鍵的 AI 捷徑">
  <img src="/images/idea-studio/ai-shortcuts-01.png" alt="劇本創意上的右鍵選單，提供總結所有角色、地點、道具與生成分鏡" />
</Frame>

這是值得記住的部分。右鍵點一則創意時，會依它的**類型**提供不同的 AI 操作。

<Tabs>
  <Tab title="大綱或劇本">
    - **總結所有角色**
    - **總結所有地點**
    - **總結所有道具**
    - **生成分鏡**

    每一項都會讀完整份文件，一次產出對應的一整組創意。
  </Tab>
  <Tab title="場景">
    - **總結所有地點**
    - **生成分鏡**
  </Tab>
</Tabs>

這些都會開啟 Build with AI，並預先選好輸出項目、把你右鍵的那則創意設為參考。存檔前你仍然可以逐項審閱。

<Tip>
  這通常是開新專案最快的路徑。把劇本貼進一則「故事」創意，然後右鍵它，分三次總結角色、地點與道具。幾分鐘之內你就會有一個內容飽滿的工作區。
</Tip>

## 下載

**下載資源**會把選定節點底下的每個圖片與影片打包成 ZIP，並保留資料夾結構。對資料夾操作會抓它底下全部；對單一創意操作則只抓那則創意的附件。
