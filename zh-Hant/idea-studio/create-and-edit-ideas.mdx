## 新增創意

選好要放的資料夾，點左側工具列的**新增創意**。

對話框會問**名稱**與**類型**。類型會依你所在的資料夾推斷，所以在角色資料夾裡建立的創意，一開始就是角色。

接下來有兩條路：

<Tabs>
  <Tab title="快速建立">
    打開**快速建立**可以完全跳過 AI，只用名稱與類型存檔，其餘之後再補。
  </Tab>
  <Tab title="用 AI 生成">
    挑一份參考大綱或劇本、描述你要什麼，也可以附上檔案（`.docx`、`.pdf`、`.txt`、`.md` 或圖片，可拖放或貼上）。AI 會幫你把創意草擬出來。
  </Tab>
</Tabs>

## 創意表單

<Frame caption="創意表單">
  <img src="/images/idea-studio/idea-form-01.png" alt="創意表單，含類型、標題、簡介、詳細內容、標籤，以及圖像與影片提示詞欄位" />
</Frame>

無論是新建還是編輯，表單的欄位都一樣。

| 欄位 | 說明 |
|---|---|
| **選定圖片** | 選擇哪一張附圖作為主圖 |
| **類型** | 大綱、劇本、角色、地點、道具、服裝、場景、鏡頭或其他 —— 也可以自己輸入 |
| **標題** | |
| **簡介** | **必填。** 這則創意被當成參考時，AI 讀的就是這段 |
| **詳細內容** | 支援 Markdown |
| **標籤** | 自由輸入 |
| **圖像提示詞** | 附有 **AI 生成**按鈕，可以幫你草擬 |
| **影片提示詞** | 同上 |

<Tip>
  寫簡介時，想像你在對一個從沒看過這個專案的人做簡報。「六十多歲、飽經風霜的高個子漁夫，總是穿著褪色的藍外套」能給模型的東西，遠多於「那個漁夫」。
</Tip>

## 之後編輯

開啟創意，用詳情檢視底部的**編輯**。同一張表單會帶著現有的值開啟。

要刪除的話，用同一處的**刪除**。刪除會要求確認。

## 建立副本

在檔案樹右鍵點創意，選**複製**。副本會加上「副本」後綴，並留在同一個資料夾。

系統資料夾不能重新命名、刪除或複製，只有裡面的創意可以。
