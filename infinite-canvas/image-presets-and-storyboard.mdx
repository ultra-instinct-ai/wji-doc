Image, dataset, and bundle nodes carry a set of one-click generation presets. Each one is a prepared prompt applied to the node's image, so you do not have to write it yourself.

Find them under **Storyboard tools** and **Generation presets** on the node toolbar, or under **More** when you drag out from a `+` handle.

**Presets work on a multi-selection.** Select a row of character images and generate character sheets for all of them in one action.

## Storyboards from text

A text node can produce a storyboard grid directly, without an image to work from. The node's content becomes the shot description.

If the text node is empty you are told so rather than getting an empty grid.

Opened from an image, dataset, or bundle node, the **storyboard builder** is a dialog for assembling frames rather than generating one grid.

Inside it you can filter the available frames, drag frames into a selection, and reorder that selection by dragging. When you finish, generated images are placed as new image nodes just to the right of the source node.

## Upscaling a cell

Grid cells are a fraction of the full image's resolution. Each cell's menu offers **Upscale to 2K** and **Upscale to 4K**, which crops that cell and regenerates it at size.

<Note>
  Cell upscaling depends on a specific model being available to your account. If it is missing, WJI says so rather than substituting another model.
</Note>

<Tip>
  Generate a 3×3 storyboard to decide coverage, pick the two or three frames that work, upscale those, and throw the rest away. Grids are for deciding, not for delivering.
</Tip>
