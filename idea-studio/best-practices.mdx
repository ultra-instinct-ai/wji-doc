---
title: "Idea Studio best practices"
description: "How to structure ideas so they pay off later in image generation and on the canvas."
---

Idea Studio rewards a little discipline early. The habits below are the ones that make a difference
once you start generating.

## Write summaries for the model, not for yourself

The summary field is what the AI reads whenever an idea is used as a reference. A summary that reads
like a reminder to yourself gives the model nothing.

| Weak | Strong |
|---|---|
| "The detective" | "Detective in her late forties, close-cropped grey hair, always in a charcoal overcoat, carries a battered leather satchel" |
| "The bar" | "Cramped basement bar, red neon behind the counter, mirrored back wall, low ceiling, always half-empty" |

You will reuse these summaries dozens of times. Ten minutes spent on them at the start saves far more
than it costs.

## Start from a script, not from blank folders

If you already have an outline or screenplay, paste it into a **Story** idea first. Then right-click
it and run **Summarize all characters**, **Summarize all locations**, and **Summarize all props**.

You get a populated workspace in minutes, and the entries are consistent with each other because
they came from one source.

## Use Enhanced mode when the material matters

Full auto is right for a first draft you expect to throw away. For work you intend to keep, Enhanced
mode's nine checkpoints let you catch a wrong reading of the material at stage two instead of
discovering it after everything is generated.

## Set a cover image early

The cover image is what appears when the idea is used as a reference and on the card in the file
tree. Generate one decent image per character and set it as the cover before you start producing
shots — everything downstream stays more consistent.

## Fill in image prompts on characters and locations

The **image prompt** field is where you put the phrasing that reliably produces this character or
place. Once it is right, you copy it into every generation instead of rewriting it from memory and
drifting.

Both the image prompt and video prompt fields have an **AI generate** button that drafts one from
the summary. It is a good starting point to then tighten by hand.

## Keep types accurate

The type on an idea drives which AI shortcuts appear on it and which folder generated ideas file
themselves into. An idea typed as "other" is one the system cannot help you with.

## Tag by production reality

Tags are free text, so use them for the axis your folders do not cover — episode, sequence, act,
shoot day, or approval status. Folders handle *what a thing is*; tags handle *where it belongs in
the schedule*.

## Put stable facts in workspace key-values

If a fact applies to the whole project rather than one idea — the series title, a fixed set of
terminology, a client's rules about what must never appear — put it in
**Settings → Key-value** instead of repeating it in every summary.
