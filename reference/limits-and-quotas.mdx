## Canvas

| Limit | Value |
|---|---|
| Zoom range | 10% to 312.5% |
| Select all | **50 nodes** |
| Select by color tag | **50 nodes** |
| Undo depth | **40 steps**, session-only, cleared on canvas switch |
| Color tags | 8 |
| Grid spacing | 20 px |
| Autosave | After ~1.5s idle, at most 3s during continuous editing |

Minimum node sizes: group 120×80, text 120×60, YouTube 240×135.

## Generation

| Limit | Set by |
|---|---|
| Reference images, video, and audio counts | The model |
| Batch size | The model |
| Video duration | The model's minimum, maximum, and step |
| Aspect ratios | The model |

When you exceed a reference limit, the newest references are kept and the **oldest are dropped from
the front of the list**.

## Workspace spending

A workspace can carry a **total** cap and a **monthly** cap, in credits. Either can be left unset.
The monthly cap resets on the 1st of the calendar month.

For features whose cost cannot be estimated in advance, a workspace that has spent **exactly** its
limit cannot start new work.
