WJI에서는 소재를 옮기는 일 대부분이 드래그로 이뤄집니다. 이 페이지는 무엇을 어디에 놓으면 무슨 일이 일어나는지 정리한 목록입니다.

## 캔버스에 놓기

| 이것을 끌면 | 결과 |
|---|---|
| 어디서든 가져온 소재(라이브러리, 기록, 사이드바, 격자) | 놓은 자리에 미디어 노드 |
| 소재 라이브러리의 데이터셋 카드 | 데이터셋 참조 노드 |
| 바탕화면의 이미지·비디오·오디오 파일 | 파일마다 미디어 노드 |
| CSV나 스프레드시트 파일 | 테이블 노드. 여러 개면 아래로 쌓입니다 |
| Markdown이나 텍스트 문서 | 텍스트 노드 |

<Note>
  소재에 URL만 있고 아직 ID가 없으면 WJI가 먼저 해석합니다. 실패하면 이미지를 소재 라이브러리에 먼저 추가한 뒤 끌라는 안내가 나옵니다.
</Note>

## 캔버스에서 Alt 드래그

**Alt**를 누르면 드래그의 의미가 달라지는데, 무엇을 잡았느냐에 따라 네 가지 다른 의미가 됩니다.

| Alt 드래그 | 놓는 곳 | 결과 |
|---|---|---|
| 미디어 또는 텍스트 노드 | **데이터셋 노드** | 그 데이터셋에 넣습니다 |
| 미디어 또는 텍스트 노드 | **소재 라이브러리의 데이터셋** | 거기에 넣습니다 |
| 미디어 또는 텍스트 노드 | **라이브러리 카드 사이의 틈** | 그 자리에 새 데이터셋을 만듭니다 |
| 미디어 노드 | **디렉터 바** | 클립을 추가하거나 클립의 주 미디어로 지정합니다 |
| **데이터셋 노드 안의 썸네일** | 다른 데이터셋 노드 | 데이터셋 사이로 소재를 옮깁니다 |
| **데이터셋 노드 안의 썸네일** | 빈 캔버스 | 그것으로 미디어 노드를 만듭니다 |
| **노드 자체** | 캔버스 어디든 | 복제합니다 |
| **연결 핸들** | 여러 노드 | 일대일 팬아웃으로 소스마다 새 노드를 만듭니다 |

의미 없는 곳에 놓으면 WJI가 조용히 실패하지 않고 유효한 대상이 어디인지 알려 줍니다.

## 데이터셋 사이로 소재 옮기기

| 여기서 | 여기로 | 결과 |
|---|---|---|
| 사이드바 데이터셋의 썸네일 | 가운데 내용 창 | 현재 데이터셋으로 이동 |
| 가운데 격자의 카드 | 사이드바의 데이터셋 카드 | 그 데이터셋으로 이동 |
| 아무 소재 | 사이드바 빈 공간 | 새 데이터셋 대화상자가 열립니다 |
| 아무 소재나 파일 | 소재 라이브러리 카드 사이의 틈 | 그 자리에 새 데이터셋을 만듭니다 |

<Warning>
  이것들은 복사가 아니라 **이동**입니다. 소재가 원본 데이터셋에서 빠지고 대상에 들어가며 양쪽 모두 저장됩니다. 사이드바는 이 드래그를 복사 작업으로 표시하지만 실제 동작은 이동입니다. 양쪽에 두고 싶으면 소재 메뉴의 **복사**를 쓰세요.
</Warning>

이미 대상에 있는 소재를 놓으면 그렇다고 알려 주고 아무것도 바뀌지 않습니다.

## 참조 슬롯에 놓기

| 대상 | 받는 것 |
|---|---|
| 통합 참조 블록 | 파일이나 소재. 이미지·비디오·오디오로 자동 분류됩니다 |
| 참조 이미지 목록 | 이미지 파일 또는 이미지 소재 |
| 참조 비디오 목록 | 비디오 파일 또는 비디오 소재 |
| 참조 오디오 목록 | 오디오 파일 또는 오디오 소재 |
| 첫/마지막 프레임 슬롯 | 이미지 파일 또는 이미지 소재 |

데이터셋에서 끌어온 소재는 데이터셋 이름과 유형을 함께 지니고 오므로, 참조로 도착한 시점에 이미 이름이 붙고 캐릭터나 장소 같은 유형도 정해져 있습니다.

<Note>
  캔버스에서 첫/마지막 프레임은 드래그로 지정하지 **않습니다**. 연결로 배정합니다. [연결과 참조](/ko/infinite-canvas/connections-and-references)를 참고하세요.
</Note>

## 바탕화면에서 파일 끌어오기

캔버스 외에 다음 영역이 파일을 직접 받습니다.

- 데이터셋 내용 창 — 이미지, 비디오, 오디오
- 소재 라이브러리. 놓은 것으로 새 데이터셋을 만듭니다
- 위에 적은 모든 참조 슬롯

데이터셋 내용 창은 **붙여넣기**도 받습니다.

<Note>
  아이디어 상세 페이지에는 업로드 버튼이 있지만 드롭 대상은 아닙니다.
</Note>

## 패널 너비 조절

사이드바와 내용 창 모두 오른쪽 가장자리에 드래그 손잡이가 있습니다.

| 창 | 범위 |
|---|---|
| 사이드바 | 240–480 px |
| 내용 | 300–480 px |

너비는 다음에도 유지됩니다.
