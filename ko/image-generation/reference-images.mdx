참조는 한 캐릭터가 백 개의 숏에서 같은 사람으로 보이게 하는 수단입니다. 일관성 면에서는 프롬프트 표현보다 참조가 더 중요합니다.

## 추가하는 여섯 가지 방법

<Steps>
  <Step title="파일 고르기">
    클릭해서 찾습니다. 여러 개 선택됩니다.
  </Step>
  <Step title="끌어다 놓거나 붙여넣기">
    프롬프트 상자에 파일을 떨어뜨리거나 붙여넣습니다. 이 경로는 이미지만 받습니다.
  </Step>
  <Step title="데이터셋에서">
    워크스페이스 아이디어에서 고릅니다. 캐릭터, 장소, 의상, 소품, 스타일로 묶여 있습니다.
  </Step>
  <Step title="IP 소재에서">
    가상 캐릭터 소재 전용 탭입니다.
  </Step>
  <Step title="결과에서">
    기록의 결과에 마우스를 올려 바로 참조로 추가합니다.
  </Step>
  <Step title="최근 사용">
    최근에 쓴 참조 여섯 개가 한 번의 클릭 거리에 있습니다.
  </Step>
</Steps>

## 참조 유형

<Frame caption="유형을 지정한 참조 이미지">
  <img src="/images/image-generation/reference-block-01.png" alt="캐릭터, 장소, 스타일 등 유형이 표시된 여러 참조 카드가 있는 참조 영역" />
</Frame>

모든 참조에는 유형이 있습니다. 카드를 클릭해 지정합니다.

| 유형 | 용도 |
|---|---|
| **캐릭터** | 인물 |
| **장소** | 장소와 세트 |
| **의상** | 옷 |
| **소품** | 물건 |
| **스타일** | 화면의 결 |
| **레이아웃** | 구도 |
| **기타** | 그 밖의 것 |

데이터셋에서 가져온 참조는 유형을 자동으로 물려받습니다. 아이디어 유형을 정확히 유지해야 할 이유가 하나 더 있는 셈입니다.

참조에는 이름도 붙일 수 있습니다. 기본값은 `image1`, `image2`이며 프롬프트에서 `@`로 지목하는 이름이기도 합니다.

## 한도

**참조 개수의 상한은 WJI가 아니라 모델이 정합니다.** 초과하면 새 참조가 뒤에 붙고 오래된 것이 앞에서 잘립니다.

Vertex 프로토콜 모델은 참조 이미지 한 장당 20 MB까지입니다.

## 참조 비디오와 참조 오디오

비디오 모드에서는 참조 비디오와 오디오도 추가할 수 있습니다.

| 제약 | 값 |
|---|---|
| 형식 | MP4 또는 MOV |
| 기본 상한 | 3개 |
| 길이 | 2–15초, 일부 모델은 30초까지 |
| 파일 크기 | 15초까지 50 MB, 15–30초는 200 MB |
| 크기 | 각 변 300–6000 px |
| 화면 비율 | 0.4에서 2.5 사이 |
| 해상도 | 1920×1080까지 |

<Warning>
  WJI가 영상의 길이를 읽지 못하면 실제 길이와 무관하게 크기 상한이 50 MB로 내려갑니다.
</Warning>

## 가중치

**참조 가중치** 슬라이더는 하나이며 모든 참조에 함께 적용됩니다. 이미지마다 따로 있지 않습니다. Midjourney 계열 모델은 모델 전용 설정에 이미지 가중치와 스타일 참조 가중치를 따로 둡니다.

## 캔버스에서는

무한 캔버스는 업로드 목록을 쓰지 않습니다. 참조는 **연결**에서 옵니다. 이미지, 비디오, 오디오 노드를 생성 노드에 이으면 그것이 참조가 됩니다. [연결과 참조](/ko/infinite-canvas/connections-and-references)를 참고하세요.
