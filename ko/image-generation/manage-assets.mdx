## 결과 보관하기

| 작업 | 위치 | 하는 일 |
|---|---|---|
| **Idea에 저장** | 결과 메뉴, 워크스페이스 전용 | 현재 아이디어에 소재를 연결합니다 |
| **Idea 커버로 지정** | 결과 메뉴 | 그 아이디어의 커버 이미지로 만듭니다 |
| **이미지에서 아이디어 만들기** | 결과 메뉴 | 이 이미지를 가진 새 아이디어를 만듭니다 |
| **소재 라이브러리에 저장** | 캔버스 노드 툴바 | 캔버스 노드의 소재를 데이터셋에 넣습니다 |
| **이동** | 소재 메뉴 | 데이터셋 사이를 옮깁니다. 원본에서는 빠집니다 |
| **복사** | 소재 메뉴 | 대상에 추가하고 원본도 유지합니다 |

**이동**과 **복사**는 트리 선택기를 열어 대상 데이터셋을 고르게 합니다. 둘 다 다중 선택을 지원하며 몇 개가 옮겨졌는지 알려 줍니다.

<Note>
  옮긴 소재가 원본 데이터셋의 커버였다면 다른 이미지가 자동으로 커버로 올라갑니다.
</Note>

## 미리보기

여섯 가지 미리보기가 있고 저마다 맞는 일이 다릅니다.

| 미리보기 | 여는 곳 | 알맞은 용도 |
|---|---|---|
| **라이트박스** | 이미지 클릭 | 훑어보기, 방향키 넘김, 확대 |
| **소재 미리보기 대화상자** | 눈 아이콘, 썸네일, 기록 | 정보·생성 상세·댓글·재사용까지 전부 |
| **데이터셋 미리보기** | 캔버스 데이터셋 노드 | 한 벌 검토와 재정렬, 항목의 즉석 편집 |
| **번들 미리보기** | 캔버스 번들 노드 | 구성원 활성화, 비활성화, 이름 변경, 재정렬 |
| **파노라마 뷰어** | 파노라마 노드 | 360° 보기 |
| **갤러리 보기** | 아이디어 상세 | 키보드로 넘기는 전체 화면 열람 |

<Warning>
  라이트박스는 이미지 전용입니다. 비디오는 일부러 쓰지 않습니다. 클릭이 재생이 아니라 다운로드가 되기 때문입니다.
</Warning>

잘 알아 둘 만한 것은 **소재 미리보기 대화상자**입니다. 기본 정보, 파일 상세, 생성 상세 일체, 복사 버튼이 달린 두 종류의 프롬프트, 사용한 참조, 태그, 댓글, 좋아요, 즉석 이름 변경, 그리고 **다시 생성에 사용**을 담고 있습니다.

## 재정렬

끌어서 순서를 바꿀 수 있는 목록이 아홉 개 있고, 저장되는 곳이 다 다릅니다.

| 목록 | 저장 형태 |
|---|---|
| 사이드바의 데이터셋 | 그 폴더의 자식 순서 |
| 소재 라이브러리의 데이터셋 | 부모의 자식 순서 |
| 데이터셋 안의 소재 | 그 데이터셋의 이미지 순서 |
| 번들 안의 소재 | 그 번들 노드의 소재 순서 |
| 캔버스 생성 노드의 참조 | 그 노드의 연결 순서 |
| 생성 폼의 참조 카드 | 제출되는 참조 배열 |
| 디렉터 바의 클립 | 타임라인 |
| 스토리보드 빌더의 숏 | 빌더의 선택 |

<Note>
  생성 폼에서는 **같은 미디어 종류**의 참조끼리만 순서를 바꿀 수 있습니다.
</Note>

## 이름 변경, 태그, 삭제

이름은 소재 미리보기 대화상자 위쪽이나 정보 패널에서 즉석에서 바꿉니다. 태그도 같은 패널에서 입력하고 Enter를 누릅니다.

삭제는 소재 메뉴, 사이드바 썸네일 팝오버, 아이디어 상세에서 할 수 있습니다. 한 개 삭제는 확인을 요구하고, 여러 개 삭제는 몇 개가 사라지는지 알려 줍니다.

## 댓글과 좋아요

둘 다 소재 미리보기 대화상자에 있으며, 워크스페이스가 허용하는지에 따릅니다. 좋아요에 마우스를 올리면 누가 언제 눌렀는지 보입니다. [뷰어 접근](/ko/workspaces/viewer-access)을 참고하세요.

## AI 설명

**이미지 설명**, **비디오 설명**, **오디오 설명**은 AI가 소재를 읽고 글로 된 설명을 돌려줍니다. 복사할 수 있습니다. 캔버스에서는 같은 기능이 결과로 텍스트 노드를 만듭니다.
