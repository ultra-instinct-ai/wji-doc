## 자주 보는 설정

| 설정 | 하는 일 |
|---|---|
| **화면 비율** | 비율 썸네일 격자. 모델이 지원하는 비율만 나옵니다 |
| **생성 개수** | 한 번에 만들 결과 수. 범위는 모델이 정합니다 |
| **참조 가중치** | 참조가 결과에 미치는 영향의 세기 |
| **Omni 가중치** | 지원 모델에서만 |
| **스타일 가중치** | 지원 모델에서만 |
| **Stylize** | 보통 0–1000, Midjourney 계열 |
| **스타일 프롬프트** | 스타일 선택기를 엽니다 |
| **길이** | 비디오 전용 |

일부 모델에는 **자동 맞춤**이라는 비율 선택지가 있습니다. 형태를 강제하지 않고 입력 이미지에 맞춥니다.

## 시드

모델이 시드를 노출하면 메인 폼에 태그로 나타납니다. `-1`은 지정하지 않음이며 모델이 알아서 고릅니다.

시드는 결과를 재현 가능하게 해 줍니다. 거의 맞는 결과가 나오면 기록 카드에서 시드를 적어 두고(시드 태그를 클릭하면 복사됩니다) 그것을 유지한 채 프롬프트를 다듬으세요.

## 모델 전용 설정

팝오버의 나머지는 모델 정의에서 만들어지며 모델을 바꾸면 함께 바뀝니다. 각 항목에는 역할을 설명하는 툴팁이 있습니다.

흔한 것들:

- **해상도**와 **출력 형식**
- **chaos** — 다양성, 0에서 100
- **quality**
- Midjourney 계열의 **이미지 가중치**와 **스타일 참조 가중치**
- **Raw 모드**와 **HD**

## 생성 개수와 스토리보드

스토리보드 레이아웃을 고르면 생성 개수가 1로 고정됩니다. 그 격자 **자체**가 출력이기 때문입니다. [스토리보드 모드](/ko/image-generation/storyboard-mode)를 참고하세요.
