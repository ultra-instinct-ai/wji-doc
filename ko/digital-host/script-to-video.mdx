프로그램은 다섯 단계를 지납니다. 이미 마친 단계로는 돌아갈 수 있지만 앞으로 건너뛸 수는 없습니다.

## 프로그램 만들기

**새 프로그램**은 이름(80자까지, 같은 폴더 안에서 중복 불가), 대사 언어, 화면 비율, 그리고 진행자·장면·의상 선택을 묻습니다.

화면 비율은 21:9, 16:9, 4:3, 1:1, 3:4, 9:16이며 기본은 16:9입니다.

## 1단계 — 대본

대본을 붙여 넣거나 `.txt`, `.md`, `.docx` 파일을 올립니다. 오래된 `.doc`는 받지 않습니다.

## 2단계 — 세그먼트로 나누기

세그먼트당 **15초** 또는 **30초**를 고릅니다. 이 둘뿐입니다. "구어체로" 같은 지시를 덧붙일 수도 있습니다.

**다시 나누기**가 세그먼트를 만들며, 각각 대사, 동작, 예상 길이, 톤을 갖습니다.

여기서 대사를 편집하고, 커서 위치에서 세그먼트를 둘로 쪼개고, 아래에 세그먼트를 추가하고, 삭제할 수 있습니다. 태그를 붙일 수 있고 **태그 제안**이 후보를 내놓습니다.

<Warning>
  다시 나누기는 **기존 세그먼트를 전부 대체합니다**. 손으로 고친 대사도 포함됩니다. WJI가 실행 전에 경고합니다.
</Warning>

## 3단계 — 내레이션

원하는 세그먼트를 체크한 뒤:

- AI로 **대사 개선 또는 번역**
- 세그먼트 하나 또는 선택 전체의 내레이션 생성
- 들어 보고, 내레이션 기록에서 테이크 전환
- 마음에 드는 것을 **승인**

각 세그먼트는 프로그램의 톤과 말하기 속도를 덮어쓸 수 있습니다. 톤은 여덟 가지 — 진지, 차분, 친근, 경쾌, 활기, 장중, 빠른 호흡, 구어체. 속도는 -50에서 100이며 0이 보통입니다.

## 4단계 — 영상

세그먼트마다 카드가 됩니다. 다음을 할 수 있습니다.

- 영상 프롬프트를 최적화한 뒤 생성
- 세그먼트별로 모델, 길이, 움직임, 해상도, 참조 이미지 변경
- 결과 **업스케일**
- **승인**

길이 기본값은 내레이션 길이 + 1초이며 최소 5초입니다. 움직임은 정지, 자연, 활발, 역동 네 가지이고, 모두 진행자가 자연스럽게 눈을 깜빡입니다.

<Note>
  내레이션이 있어야 세그먼트에 영상을 붙일 수 있습니다. 생성하기 전까지 상태는 **내레이션 없음**으로 남습니다.
</Note>

일괄 생성은 진행 대화상자를 열어 먼저 확인한 뒤, 끝나는 세그먼트를 차례로 보고합니다. 실행 중에는 닫을 수 없습니다.

## 5단계 — 완료

탭이 셋입니다. **세그먼트**, **생성 기록**, **크레딧 보고서**.

내보내기 선택지:

| 내보내기 | 결과물 |
|---|---|
| **모든 내레이션 다운로드** | `001-audio.mp3` 등이 담긴 ZIP |
| **모든 영상 다운로드** | `001-video.mp4` 등이 담긴 ZIP |
| **모든 소재 다운로드** | `audio/`와 `video/` 폴더가 담긴 ZIP |
| **이어붙인 영상 다운로드** | 브라우저에서 이어붙인 MP4 하나 |
| **보고서 JSON 내보내기** | 전체 매니페스트 |
| **CSV 내보내기** | 생성 기록 |

CSV는 **현재 필터가 적용된 기록**을 내보냅니다. 전부가 아닙니다. 열은 시각, 소요 시간, 종류, 세그먼트, 조작자, 프롬프트, 크레딧입니다.

## 상태와 비용

영상 상태: 승인됨, 생성 중, 내레이션 없음, 실패, 생성됨, 미리보기 없음, 대기 중. 다시 만든 세그먼트에는 재시도 횟수가 표시됩니다.

자동 재시도는 없습니다. 직접 생성을 다시 누르세요.

<Warning>
  **실패한 생성도 요금이 부과되며** 프로그램의 누적 크레딧에 포함됩니다. 크레딧 보고서의 성공률은 분모에 실패와 재시도를 세기 때문에, 결과적으로 잘 나온 프로그램에서도 낮아 보일 수 있습니다.
</Warning>
