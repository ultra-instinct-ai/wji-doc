---
title: "자주 묻는 질문"
description: "가장 많이 나오는 질문에 대한 짧은 답."
---

<AccordionGroup>
  <Accordion title="시작된 생성을 취소할 수 있나요?">
    없습니다. WJI 어디에도 취소나 중지 기능이 없습니다. 생성 버튼의 예상 비용이 유일한 확인 지점입니다. 제출 전에, 특히 배치와 긴 영상에서는 꼭 읽으세요.
  </Accordion>

  <Accordion title="인페인팅처럼 이미지의 일부만 편집할 수 있나요?">
    직접은 안 됩니다. WJI에는 인페인팅, 아웃페인팅, 배경 제거, 변형이 없습니다. 편집은 원본을 참조로 넣고 프롬프트 템플릿을 적용해 다시 생성하는 방식입니다. **캐릭터** 템플릿 분류가 얼굴 교체, 의상, 표정, 포즈를 다룹니다.

    비디오는 예외입니다. 캔버스에서는 클립의 **일부**를 다시 만들어 이어 붙일 수 있습니다. [비디오 도구](/ko/infinite-canvas/video-tools)를 보세요.
  </Accordion>

  <Accordion title="왜 네거티브 프롬프트 항목이 없나요?">
    WJI에는 없습니다. 피하고 싶은 것이 아니라 원하는 것을 쓰세요.
  </Accordion>

  <Accordion title="워크스페이스 전체를 복제할 수 있나요?">
    없습니다. 개별 아이디어와 소재를 복사하고 캔버스 간에 노드를 복사할 수는 있지만, 워크스페이스 자체는 복제되지 않습니다.
  </Accordion>

  <Accordion title="왜 제 워크스페이스에는 앱이 세 개만 보이나요?">
    기본으로 세 개가 표시됩니다. 아이디어 도구, 아이디어 이미지 생성, 무한 캔버스입니다. 계정에 접근 권한이 있으면 디지털 진행자를 추가할 수 있습니다. 시스템에는 다른 앱도 있지만 워크스페이스에서는 쓰이지 않습니다.
  </Accordion>

  <Accordion title="모델을 바꿨더니 참조가 사라진 이유는?">
    새 모델이 받는 참조가 더 적어서 초과분이 제거되었습니다. 그것도 **목록 앞쪽부터**, 곧 처음 넣은 것부터입니다. 모델을 바꿀 때마다 참조 목록을 확인하세요.
  </Accordion>

  <Accordion title="캔버스에서 왜 어떤 건 실행 취소가 안 되나요?">
    실행 취소는 이동, 크기 조절, 정렬, 삭제, 연결, 태그, 텍스트 편집을 다룹니다. 만들기, 붙여넣기, 복제, 업로드, 생성 결과, 그룹화는 **다루지 않습니다**. 또 40단계만 유지되며 캔버스를 바꾸면 지워집니다.
  </Accordion>

  <Accordion title="워크스페이스 안에서 어떻게 검색하나요?">
    워크스페이스 목록, 캔버스, 프롬프트 프리셋은 검색됩니다. **파일 트리에는 검색창이 없습니다.** 폴더와 태그로 아이디어를 찾을 수 있게 유지하세요.
  </Accordion>

  <Accordion title="VIP에서 SVIP로 어떻게 올리나요?">
    현재 구독을 해지하고 기간이 끝나기를 기다린 뒤 SVIP를 구독하세요. 직접적인 업그레이드나 다운그레이드는 없습니다.
  </Accordion>

  <Accordion title="크레딧은 어느 것부터 쓰이나요?">
    가장 빨리 만료되는 통부터입니다. 만료가 없는 크레딧끼리는 구매분보다 지급분이 먼저 쓰입니다.
  </Accordion>

  <Accordion title="실패한 생성도 요금이 나가나요?">
    일반 생성에서는 아닙니다. 실패는 환불되고 배치의 일부 실패도 비례 환불됩니다. **디지털 진행자는 다릅니다.** 거기서는 실패한 생성에도 요금이 붙고 프로그램 합계에 포함됩니다.
  </Accordion>

  <Accordion title="결제 기록을 내보낼 수 있나요?">
    없습니다. CSV, Excel, PDF 내보내기가 없습니다. 완료된 주문에 대해 개별 Stripe 영수증은 내려받을 수 있습니다.
  </Accordion>

  <Accordion title="조직 초대를 취소할 수 있나요?">
    없습니다. 조직 초대는 취소되지 않으며 7일 뒤 만료됩니다. **워크스페이스** 초대 링크는 취소할 수 있고 한 번에 하나만 유효합니다.
  </Accordion>

  <Accordion title="조직 이름을 바꿀 수 있나요?">
    없습니다. 이름은 생성 시 고정되고 아바타도 올릴 수 없습니다.
  </Accordion>

  <Accordion title="조직을 스스로 나갈 수 있나요?">
    스스로는 안 됩니다. 소유자나 관리자가 내보내야 합니다.
  </Accordion>

  <Accordion title="팀원이 캔버스에서 제 커서를 볼 수 있나요?">
    볼 수 없습니다. 캔버스는 실시간으로 동기화되어 팀원의 편집 결과는 보이지만, 접속 커서나 아바타, 선택 강조는 없습니다.
  </Accordion>

  <Accordion title="캔버스를 이미지나 PDF로 내보낼 수 있나요?">
    없습니다. 캔버스의 소재를 내려받거나 디렉터 바 타임라인을 영상이나 NLE 프로젝트로 내보낼 수는 있지만, 보드 자체를 그림이나 파일로 내보낼 수는 없습니다.
  </Accordion>
</AccordionGroup>
