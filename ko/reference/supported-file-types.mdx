## 업로드 크기 한도

| 대상 | 한도 |
|---|---|
| 이미지, 오디오, 문서 | **25 MB** |
| 비디오 | **200 MB** |

## 참조 비디오

참조 비디오는 일반 업로드보다 제한이 빡빡하고 길이에 따라 달라집니다.

| 길이 | 최대 크기 |
|---|---|
| 15초까지 | **50 MB** |
| 15~30초 | **200 MB** |

| 제약 | 값 |
|---|---|
| 최소 길이 | 2초 |
| 최대 길이 | 30초 |
| 크기 | 각 변 300~6000 px |
| 화면 비율 | 0.4에서 2.5 사이 |
| 해상도 | 1920×1080까지 |
| 기본 개수 | 모델이 달리 정하지 않으면 3개 |

<Warning>
  WJI가 영상의 길이를 읽지 못하면 실제 길이와 무관하게 크기 한도가 **50 MB**로 내려갑니다. 다시 인코딩하면 대개 해결됩니다.
</Warning>

지원하는 비디오 확장자: `mp4`, `mov`, `webm`, `m4v`, `mkv`, `avi`. 참조 비디오는 **MP4와 MOV**를 받습니다.

## 참조 이미지

| 제약 | 값 |
|---|---|
| 짧은 변 최소 | **300 px** |
| 한 장 최대 | Vertex 프로토콜 모델에서 20 MB |
| 개수 | 모델이 정합니다 |

## 참조 오디오

요구 사항은 모델마다 다릅니다. Seedance 모델은 **1.8초에서 15초**를 기대합니다.

## 문서

| 기능 | 받는 형식 |
|---|---|
| Build with AI, 아이디어 만들기 | `.docx`, `.pdf`, `.txt`, `.md`, 이미지 |
| 디지털 진행자 대본 | `.txt`, `.md`, `.docx` — `.doc`는 **안 됩니다** |
| 캔버스 텍스트 노드 가져오기 | Markdown과 텍스트 문서 |
| 캔버스 테이블 노드 | CSV와 스프레드시트 파일 |

## 워크스페이스 아바타

JPG와 PNG.

## 다운로드

| 다운로드 | 형식 |
|---|---|
| 단일 소재 | 원본 파일 |
| 폴더, 데이터셋, 다중 선택 | ZIP, 폴더 구조 유지 |
| 캔버스 텍스트 노드 | Markdown, 일반 텍스트, Word |
| 디렉터 바 영상 | MP4 |
| 디렉터 바 프로젝트 | `timeline.otio`, `timeline.edl`, `media/`, `manifest.json`이 든 ZIP |
| 디지털 진행자 기록 | CSV |
