## 생성 실패

생성이 실패하면 WJI는 공급자의 오류 코드가 아니라 알기 쉬운 이유를 보여 줍니다. 모두 33가지이며, 아래는 무엇을 해야 하는지에 따라 묶은 것입니다.

### 내용이 차단됨

| 메시지 | 할 일 |
|---|---|
| **실존 인물이 포함됨** | 참조 이미지에 실제 사람이 있습니다. 교체하세요 |
| **프롬프트가 안전하지 않음** | 더 중립적인 표현으로 바꾸세요 |
| **비디오/오디오/이미지 내용 제한** | *출력*이 제한에 걸렸습니다. 프롬프트를 조정하세요 |
| **안전 정책에 걸림** | 참조일 수도 출력일 수도 있습니다. 확실치 않으면 둘 다 바꾸세요 |
| **금지된 내용 포함** | 이미지를 만들 수 없었습니다. 프롬프트나 참조를 조정하세요 |
| **저작권 관련 가능성** | 프롬프트나 참조 소재를 바꾸세요 |
| **출력 오디오의 저작권 가능성** | 프롬프트, 대사, 참조 오디오를 조정하세요 |

내용 차단은 WJI가 아니라 모델 공급자가 판단합니다. 재시도보다 표현을 바꾸는 편이 낫습니다.

### 참조 소재가 잘못됨

| 메시지 | 할 일 |
|---|---|
| **참조 이미지가 너무 작음** | 짧은 변이 최소 **300 px**여야 합니다 |
| **오디오가 너무 긺** | 줄이세요. Seedance는 보통 15초 이하가 필요합니다 |
| **오디오가 너무 짧음** | Seedance 2.0 참조 오디오는 보통 1.8초 이상이 필요합니다 |
| **오디오 형식 미지원** | 변환하세요 |
| **비디오 길이가 부적합** | 모델의 요구 사항을 확인하세요 |
| **편집 비디오 길이가 범위 밖** | 비디오 편집에는 **4초에서 30초**의 참조 클립이 필요합니다 |
| **해상도가 너무 낮음** | 더 높은 해상도의 참조 비디오를 쓰세요 |
| **참조 소재 없음** | 참조 이미지나 참조 비디오를 최소 하나 추가하세요 |
| **참조 충돌** | 음성 생성은 참조 이미지와 참조 오디오를 함께 쓸 수 없습니다. 하나만 남기세요 |

### 문제가 프롬프트에 있음

| 메시지 | 할 일 |
|---|---|
| **프롬프트 없음** | 입력하세요 |
| **프롬프트가 너무 짧음** | 설명을 더하세요 |
| **프롬프트가 작업 유형과 안 맞음** | 생성 모드 프롬프트에 편집이나 연장 관련 단어가 있습니다. 작업 유형을 바꾸거나 표현을 고치세요 |
| **편집 의도 없음** | 편집 모드에는 *edit*, *add*, *remove*, *replace* 같은 단어가 필요합니다 |
| **연장 의도 없음** | 연장 모드에는 *extend*나 *continue* 같은 단어가 필요합니다 |
| **작업 유형 불일치** | 작업 유형, 화면 비율, 길이, 프롬프트를 함께 확인하세요. 편집과 연장에는 적응형 비율과 참조 비디오가 필요합니다 |

### 아무것도 오지 않음

| 메시지 | 할 일 |
|---|---|
| **이미지가 생성되지 않음** | 프롬프트나 참조를 조정하고 다시 시도하세요 |
| **모델에서 결과 없음** | 위와 같습니다 |
| **생성 시간 초과** | 잠시 뒤 다시 시도하세요 |

### 서비스 문제

| 메시지 | 할 일 |
|---|---|
| **서비스 오류** | 일시적입니다. 곧 다시 시도하세요 |
| **할당량 소진** | 여러분의 크레딧이 아니라 공급자 용량입니다. 나중에 시도하세요 |
| **네트워크 오류** | 연결을 확인하고 다시 시도하세요 |
| **잘못된 요청**/**잘못된 매개변수** | 프롬프트와 참조를 확인하세요 |
| **생성 실패** | 더 구체적인 이유가 없을 때의 기본 메시지 |

## 그 밖의 흔한 문제

**"소재 ID를 확인할 수 없습니다. 이미지를 먼저 소재 라이브러리에 추가하세요"** — WJI가 식별하지 못하는 이미지를 끌었습니다. 소재 라이브러리에 저장한 뒤 거기서 끌어오세요.

**생성이 돌아가는데 멈추고 싶습니다** — 멈출 수 없습니다. 취소가 없습니다. 완료나 실패를 기다리세요.

**모델을 바꾸니 참조가 사라졌습니다** — 새 모델이 받는 개수가 적어서 오래된 것이 잘렸습니다. [모델 선택](/ko/image-generation/models)을 보세요.

**요청하지 않았는데 결과가 스타일화됩니다** — 스타일 프리셋이 아직 선택되어 있습니다. 프롬프트 상자에 보이지 않은 채 최종 프롬프트에 덧붙습니다. [프롬프트 작성](/ko/image-generation/prompts)을 보세요.

**실행 취소로 지운 것을 못 되돌립니다** — 실행 취소가 무엇을 포함하는지 확인하세요. 만들기, 붙여넣기, 복제, 업로드, 생성 결과는 대상이 아니고, 캔버스를 바꾸면 기록이 지워집니다. [자동 저장과 실행 취소](/ko/infinite-canvas/autosave-and-undo)를 보세요.

**구독을 업그레이드할 수 없습니다** — 업그레이드 경로가 없습니다. 해지하고 기간이 끝나기를 기다린 뒤 원하는 요금제를 구독하세요. [구독](/ko/billing/subscriptions)을 보세요.

**"워크스페이스가 총액/월간 한도에 도달했습니다"** — 지출 상한이 설정되어 있습니다. [워크스페이스 설정](/ko/workspaces/settings)을 보세요.

**"이 조직의 멤버가 아닙니다" 또는 "조직이 중지되었습니다"** — 자동으로 개인 공간으로 돌아갑니다. [신분 전환](/ko/organizations/switching-context)을 보세요.

**조직에서 멤버를 내보낼 수 없습니다** — 그 사람이 아직 어떤 워크스페이스의 예산 책임자입니다. 먼저 바꾸세요.

**공유한 초대 링크를 멈추고 싶습니다** — 워크스페이스 링크는 취소할 수 있지만 조직 초대는 취소할 수 없고 7일 뒤 만료됩니다.
