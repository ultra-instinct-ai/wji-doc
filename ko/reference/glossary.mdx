---

<AccordionGroup>
  <Accordion title="소재 Asset">
    생성하거나 업로드한 모든 미디어 — 이미지, 비디오, 오디오 파일. 소재는 아이디어에 속하고, 캔버스에 나타나며, 참조로 다시 쓸 수 있습니다.
  </Accordion>

  <Accordion title="소재 라이브러리">
    캔버스에서 `⌘B`로 여는 패널. 워크스페이스의 폴더와 데이터셋을 보여 줍니다.
  </Accordion>

  <Accordion title="소재 팩 Bundle">
    연결로 모은 여러 미디어를 묶는 캔버스 노드. 연결 하나가 많은 참조를 나를 수 있게 해 줍니다.
  </Accordion>

  <Accordion title="캔버스">
    무한 캔버스 앱 안의 보드 하나. 워크스페이스는 여러 개를 가질 수 있습니다.
  </Accordion>

  <Accordion title="크레딧">
    WJI의 소비 단위. [크레딧 작동 방식](/ko/billing/how-credits-work)을 보세요.
  </Accordion>

  <Accordion title="데이터셋">
    아이디어와 거기 붙은 미디어가 저장된 형태. 캔버스의 데이터셋 노드가 이것을 가리킵니다.
  </Accordion>

  <Accordion title="디렉터 바">
    캔버스 아래쪽의 타임라인. 클립을 조립하고 내보냅니다.
  </Accordion>

  <Accordion title="최종 프롬프트">
    프롬프트를 AI가 최적화한 판이자 실제로 모델에 보내지는 내용. 여러분이 쓴 문장은 사용자 프롬프트로 따로 보관됩니다.
  </Accordion>

  <Accordion title="생성 노드">
    미디어를 만들어 내는 캔버스 노드. 참조가 연결을 통해 여기에 닿습니다.
  </Accordion>

  <Accordion title="아이디어">
    아이디어 도구의 항목 하나 — 캐릭터, 장소, 소품, 숏, 개요, 대본 — 요약, 내용, 태그, 프롬프트, 첨부 미디어를 갖습니다.
  </Accordion>

  <Accordion title="아이디어 도구">
    글로 된 자료를 기록하고 정리하는 앱.

    일부 화면에는 **Creative Tools**로 표시됩니다. 같은 앱입니다.
  </Accordion>

  <Accordion title="노드">
    캔버스에 놓는 모든 것. 열네 가지가 있습니다. [노드 종류](/ko/infinite-canvas/node-types)를 보세요.
  </Accordion>

  <Accordion title="참조">
    생성을 이끌기 위해 넣는 미디어나 텍스트. 단독 생성기에서는 직접 쌓는 목록이고, 캔버스에서는 연결을 통해 들어옵니다.
  </Accordion>

  <Accordion title="시드">
    생성을 재현 가능하게 만드는 숫자. `-1`은 지정하지 않음입니다.
  </Accordion>

  <Accordion title="세그먼트">
    디지털 진행자에서 대사 한 대목과 그에 딸린 내레이션 및 영상 클립.
  </Accordion>

  <Accordion title="스토리보드 모드">
    숏이나 앵글의 격자를 한 장의 이미지로 만드는 생성 모드.
  </Accordion>

  <Accordion title="작업 모드">
    Seedance 비디오 모델에서 이번 실행이 생성인지, 편집인지, 연장인지. 프롬프트 표현이 모드와 맞아야 합니다.
  </Accordion>

  <Accordion title="워크스페이스">
    프로젝트 하나를 담는 그릇 — 아이디어, 소재, 캔버스, 멤버, 설정.
  </Accordion>
</AccordionGroup>
