왼쪽 패널의 파일 트리가 정리하는 곳이며, 진가는 우클릭에 있습니다.

## 일반 작업

아이디어나 폴더를 우클릭하세요.

| 작업 | 대상 | 설명 |
|---|---|---|
| **채팅에 추가** | 아이디어 | 아이디어를 워크스페이스 AI 채팅에 맥락으로 보냅니다 |
| **〈유형〉 추가** | 폴더 | 문구가 폴더에 맞춰 바뀝니다 — 캐릭터 안에서는 "캐릭터 추가" |
| **새 폴더** | 폴더 | 하위 폴더를 만듭니다 |
| **복사** | 아이디어 | "사본" 접미사를 붙여 복제합니다 |
| **이름 변경** | 둘 다 | |
| **삭제** | 둘 다 | |
| **소재 다운로드** | 둘 다 | 폴더 구조를 유지한 ZIP |

여섯 개 시스템 폴더 — 스토리, 캐릭터, 장소, 소품, 숏, 기타 — 는 이름 변경, 삭제, 복사가 되지 않습니다.

<Note>
  파일 트리에는 검색창이 없습니다. 폴더와 태그로 찾을 수 있는 상태를 유지하세요.
</Note>

## AI 단축 기능

알아 둘 가치가 있는 부분입니다. 아이디어를 우클릭하면 그 **유형**에 따라 AI 작업이 나타납니다.

<Tabs>
  <Tab title="개요 또는 대본">
    - **모든 캐릭터 요약**
    - **모든 장소 요약**
    - **모든 소품 요약**
    - **스토리보드 생성**

    각각 문서 전체를 읽고 해당하는 아이디어 한 벌을 한 번에 만듭니다.
  </Tab>
  <Tab title="씬">
    - **모든 장소 요약**
    - **스토리보드 생성**
  </Tab>
</Tabs>

이 기능들은 모두 Build with AI를 열고, 출력이 미리 선택되고, 우클릭한 아이디어가 참조로 설정된 상태로 시작합니다. 저장 전 검토는 그대로 할 수 있습니다.

<Tip>
  새 프로젝트를 시작할 때 보통 이게 가장 빠릅니다. 대본을 스토리 아이디어에 붙여 넣고, 우클릭해 캐릭터, 장소, 소품을 세 번에 나눠 요약하세요. 몇 분이면 내용이 채워진 워크스페이스가 생깁니다.
</Tip>

## 다운로드

**소재 다운로드**는 선택한 노드 아래의 모든 이미지와 영상을 폴더 구조를 유지한 채 ZIP으로 모읍니다. 폴더에 적용하면 그 아래 전부를, 아이디어 하나에 적용하면 그 아이디어의 첨부만 가져옵니다.
