## 아이디어 추가

넣고 싶은 폴더를 고르고 왼쪽 툴바에서 **아이디어 추가**를 클릭합니다.

대화상자는 **이름**과 **유형**을 묻습니다. 유형은 현재 폴더에서 추정되므로 캐릭터 폴더에서 만든 아이디어는 처음부터 캐릭터입니다.

여기서 두 갈래가 있습니다.

<Tabs>
  <Tab title="빠른 생성">
    **빠른 생성**을 켜면 AI를 완전히 건너뛰고 이름과 유형만으로 저장합니다. 나머지는 나중에 채웁니다.
  </Tab>
  <Tab title="AI로 생성">
    참조할 개요나 대본을 고르고, 원하는 바를 설명하고, 필요하면 파일(`.docx`, `.pdf`, `.txt`, `.md` 또는 이미지 — 끌어다 놓거나 붙여넣기)을 붙입니다. AI가 아이디어 초안을 만들어 줍니다.
  </Tab>
</Tabs>

## 아이디어 양식

<Frame caption="아이디어 양식">
  <img src="/images/idea-studio/idea-form-01.png" alt="유형, 제목, 요약, 상세 내용, 태그, 이미지와 비디오 프롬프트 항목이 있는 아이디어 양식" />
</Frame>

새로 만들 때나 편집할 때나 항목은 같습니다.

| 항목 | 설명 |
|---|---|
| **선택한 이미지** | 어느 첨부 이미지를 커버로 쓸지 |
| **유형** | 개요, 대본, 캐릭터, 장소, 소품, 의상, 씬, 숏, 기타 — 직접 입력해도 됩니다 |
| **제목** | |
| **요약** | **필수.** 이 아이디어가 참조로 쓰일 때 AI가 읽는 부분입니다 |
| **상세 내용** | Markdown |
| **태그** | 자유 입력 |
| **이미지 프롬프트** | 초안을 만들어 주는 **AI 생성** 버튼 포함 |
| **비디오 프롬프트** | 위와 동일 |

<Tip>
  요약은 이 프로젝트를 한 번도 본 적 없는 사람에게 브리핑한다고 생각하고 쓰세요. "60대의 키 큰 어부, 풍파에 시달린 얼굴, 늘 빛바랜 파란 코트 차림"이 "그 어부"보다 모델에게 줄 것이 훨씬 많습니다.
</Tip>

## 나중에 편집하기

아이디어를 열고 상세 보기 아래의 **편집**을 씁니다. 현재 값이 들어간 같은 양식이 열립니다.

삭제도 같은 자리의 **삭제**로 합니다. 삭제에는 확인 절차가 있습니다.

## 복제하기

파일 트리에서 아이디어를 우클릭하고 **복사**를 고릅니다. 복제본은 "사본" 접미사가 붙어 같은 폴더에 놓입니다.

시스템 폴더는 이름 변경, 삭제, 복사가 안 되며 그 안의 아이디어만 가능합니다.
