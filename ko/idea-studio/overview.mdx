**아이디어 도구**는 프로젝트의 글이 사는 곳입니다. 이야기를 이루는 재료 — 누가 나오는지, 어디서 벌어지는지, 화면에 무엇이 담기는지 — 를 모으며, 여기에 쓴 것은 모두 다른 앱에서 참조로 쓸 수 있습니다.

<Note>
  일부 화면에는 여전히 **Creative Tools**로 표시됩니다. 같은 앱입니다.
</Note>

## 폴더

모든 워크스페이스의 아이디어 도구에는 여섯 개의 폴더가 미리 만들어져 있습니다.

| 폴더 | 담기는 것 |
|---|---|
| **스토리** | 개요, 전제, 완성된 대본 |
| **캐릭터** | 인물. 설명과 참조 이미지 포함 |
| **장소** | 장소와 세트 |
| **소품** | 화면에 등장하는 물건 |
| **숏** | 개별 숏. 카메라와 구도 메모 포함 |
| **기타** | 위 어디에도 맞지 않는 것 |

이 여섯은 시스템 폴더입니다. 이름 변경, 삭제, 복사는 안 되지만 안에 하위 폴더는 만들 수 있습니다.

## 아이디어가 담는 것

각 아이디어는 다음을 갖춘 카드입니다.

- **유형** — 개요, 대본, 캐릭터, 장소, 소품, 의상, 씬, 숏, 기타
- **요약**(필수)
- **상세 내용**(Markdown)
- **태그**
- **이미지 프롬프트**와 **비디오 프롬프트**
- 연결된 **이미지와 영상**
- 자유 형식 **메타데이터**

요약은 보이는 것보다 중요합니다. 생성할 때 이 아이디어가 참조로 쓰이면 AI가 읽는 것이 바로 요약입니다.

## 아이디어는 어디로 가나

아이디어는 최종 결과물이 아닙니다. 하나의 아이디어에서 다음을 할 수 있습니다.

- [아이디어 이미지 생성](/ko/image-generation/overview)에서 그 아이디어를 참조로 이미지와 영상을 생성
- [캔버스](/ko/infinite-canvas/overview)로 끌어다 데이터셋 노드로 만들기
- 워크스페이스 AI 채팅에 맥락으로 전달

상세 보기에서 아이디어의 아바타를 클릭하면 그 아이디어가 선택된 상태로 아이디어 이미지 생성으로 바로 이동합니다.
