**Build with AI**는 빈 워크스페이스를 채우는 가장 빠른 방법입니다. 개요, 대본, 혹은 전제 하나만 주면 캐릭터, 장소, 소품, 숏을 아이디어로 만들어 저장합니다.

왼쪽 툴바의 **AI 생성** 버튼으로 엽니다.

## 무엇을 주나요

<Steps>
  <Step title="참조(선택)">
    이 워크스페이스에 있는 기존 개요나 대본을 고릅니다. 드롭다운에는 유형이 개요 또는 대본인 아이디어가 나옵니다.
  </Step>
  <Step title="전제(선택)">
    스토리 영감 상자에 아이디어를 입력합니다.
  </Step>
  <Step title="또는 파일">
    `.docx`, `.pdf`, `.txt`, `.md` 또는 이미지를 업로드합니다. 끌어다 놓거나 붙여넣어도 됩니다.
  </Step>
</Steps>

## 무엇을 받나요

원하는 출력을 고릅니다. 여섯 개 모두 기본 선택입니다.

| 출력 | 만들어지는 것 |
|---|---|
| **개요** | 이야기의 아웃라인 |
| **대본** | 대본 |
| **캐릭터** | 인물마다 하나 |
| **장소** | 장소마다 하나 |
| **소품** | 물건마다 하나 |
| **숏** | 숏마다 하나 |

**숏**을 고르면 숏 개수 입력란이 추가됩니다. `0`으로 두면 AI가 개수를 정합니다.

## 실행하는 두 가지 방법

<Tabs>
  <Tab title="완전 자동">
    처음부터 끝까지 실행하고 끝나면 결과를 보여 줍니다. 입력을 신뢰하고 초안을 빨리 얻고 싶을 때 쓰세요.
  </Tab>
  <Tab title="강화 모드">
    개요, 대본, 캐릭터, 장소, 소품, 숏, 프롬프트, 데이터셋, 저장의 아홉 단계를 거치며 각 단계에서 멈춰 확인하고 고칠 수 있습니다. 느리지만 재료를 잘못 읽은 지점을 초반에 잡아내, 전부 다시 만드는 일을 피할 수 있습니다.
  </Tab>
</Tabs>

## 저장 전 검토

승인하기 전까지는 워크스페이스에 아무것도 기록되지 않습니다. 결과 패널은 편집 가능한 표입니다.

- 카드를 하나씩 켜고 끄기
- 이름, 설명, 상세, 연출 메모 편집
- **대상 폴더** 선택, 필요하면 즉석에서 새 폴더 만들기
- AI가 떠올리지 못한 카드 추가
- 숏에는 숏 번호, 숏 사이즈, 카메라 무빙, 앵글, 길이 입력

각 카드에는 상태 배지(대기 중, 처리 중, 실행 중, 완료, 실패)가 붙습니다.

저장하면 아이디어는 유형에 맞는 폴더로 자동 분류됩니다.

<Warning>
  같은 재료로 Build with AI를 다시 돌리면 **새** 아이디어가 만들어집니다. 이미 저장한 것을 갱신하지 않습니다.
</Warning>
