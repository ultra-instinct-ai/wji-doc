## 상단 내비게이션

워크스페이스 밖의 모든 페이지는 같은 헤더를 공유합니다.

<Frame caption="WJI 상단 내비게이션">
  <img src="/images/_placeholder.png" alt="채팅, 워크스페이스, 에이전트, 이미지 생성기 링크와 오른쪽 계정 컨트롤을 보여 주는 WJI 상단 내비게이션 바" />
</Frame>

| 링크 | 열리는 화면 |
|---|---|
| **채팅** | 워크스페이스에 속하지 않은 에이전트와의 대화 |
| **워크스페이스** | 워크스페이스 목록 — 대부분의 작업이 여기서 시작됩니다 |
| **에이전트** | 에이전트를 둘러보고 직접 만든 것을 관리합니다 |
| **이미지 생성기** | 워크스페이스에 묶이지 않은 단독 생성 도구 |

일부 계정에만 보이는 링크가 두 개 더 있습니다. **IP/캐릭터**는 소재 그룹 권한이 필요하고, **관리자**는 관리자에게만 표시됩니다.

헤더 오른쪽에는 테마 전환, 언어 전환, 진행 중인 생성을 추적하는 작업 추적기, 알림 벨, 프로필 메뉴가 있습니다. 프로필 메뉴에는 **대시보드**, **사용량**, **결제 내역**, **지원**, 조직 전환기도 들어 있습니다.

## 워크스페이스 목록

**워크스페이스**를 열면 **내 워크스페이스**가 표시됩니다. 각 카드에는 커버, 화면 비율, 언어, 멤버, 마지막 업데이트 시각이 나타납니다. 카드의 별을 클릭하면 즐겨찾기에 추가됩니다.

카드 위에서 다음을 할 수 있습니다.

- **전체**, **내 것**, **나에게 공유됨**, **즐겨찾기**로 필터링
- 업데이트 또는 생성 시각 기준으로 오름차순·내림차순 정렬
- 키워드로 검색
- **워크스페이스 만들기** 클릭

## 워크스페이스 안

워크스페이스를 열면 화면 전체가 3단 레이아웃으로 바뀝니다.

<Frame caption="워크스페이스 레이아웃">
  <img src="/images/_placeholder.png" alt="앱 바, 앱 아이콘과 파일 트리가 있는 왼쪽 패널, 주 콘텐츠 영역, AI 채팅 패널을 보여 주는 워크스페이스 레이아웃" />
</Frame>

위쪽 **앱 바**에는 목록으로 돌아가는 화살표, 워크스페이스 이름, 그리고 볼 권한이 있다면 워크스페이스 잔액을 나타내는 크레딧 배지가 있습니다.

**왼쪽 패널**은 앱을 전환하는 곳입니다. 워크스페이스에는 기본으로 세 개가 표시됩니다.

앱 아이콘 아래에는 툴바와 파일 트리가 있으며 내용은 선택한 앱에 따라 달라집니다. 이 패널에는 작업 추적기와 설정 톱니바퀴도 있습니다. 오른쪽 가장자리를 끌어 너비를 조절하거나 좁은 레일로 접을 수 있습니다.

<Note>
  무한 캔버스를 열면 왼쪽 패널이 자동으로 레일로 접히며, 캔버스에 있는 동안에는 펼칠 수 없습니다.
</Note>

**주 영역**에는 선택한 앱이 표시됩니다. **오른쪽 패널**은 워크스페이스를 범위로 하는 AI 채팅으로, 아이디어 도구에서는 보이지만 캔버스에서는 보이지 않습니다.

## 처음 방문할 때

워크스페이스를 처음 열면 짧은 튜토리얼이 레이아웃을 안내합니다. 닫을 수 있으며, 체크박스를 켜면 해당 워크스페이스에서는 다시 자동으로 표시되지 않습니다.
