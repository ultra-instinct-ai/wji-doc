캡슐 툴바의 물음표를 누르면 앱 안에서도 이 목록을 볼 수 있습니다. Mac 키로 적었으며, Windows에서는 `⌘`를 `Ctrl`로 바꿔 읽으세요.

## 노드

| 단축키 | 동작 |
|---|---|
| `I` | 이미지 생성 노드 만들기 |
| `V` | 비디오 생성 노드 만들기 |
| `A` | 오디오 생성 노드 만들기 |
| `/` | 프롬프트 프리셋에서 텍스트 노드 만들기 |
| `⌥` + `I` / `V` / `A` | 선택한 노드마다 일대일 생성 |
| 빈 곳 더블클릭 | 만들기 메뉴 |
| 텍스트 노드 더블클릭 | 편집 |
| `⌘ ↵` | 텍스트 편집 확정 |
| `⌥` + 드래그 | 노드 복제, 또는 데이터셋에 넣기 |
| `+` 드래그 | 다중 선택에서 연결 |
| `⌥` + `+` 드래그 | 다중 선택에서 팬아웃 |

## 편집

| 단축키 | 동작 |
|---|---|
| `⌘Z` | 실행 취소 |
| `⌘⇧Z`(Windows `Ctrl+Y`) | 다시 실행 |
| `⌘C` | 복사 |
| `⌘V` | 붙여넣기 |
| `⌘D` | 복제 |
| `⌫` 또는 `Del` | 삭제 |
| `Esc` | 취소 또는 선택 해제 |
| `⌘A` | 전체 선택(50개까지) |
| `⌘G` | 그룹화 |

## 뷰포트

| 단축키 | 동작 |
|---|---|
| `Space` + 드래그 | 이동 |
| 가운데 버튼 드래그 | 이동 |
| 스크롤 | 세로 이동, `Shift` + 스크롤은 가로 |
| `⌘` + 스크롤 | 확대·축소 |
| `⌘ =` | 확대 |
| `⌘ -` | 축소 |
| `⇧Z` | 모든 노드에 맞추기 |
| `Tab` 또는 `Z` | 선택 항목으로 확대 |
| `H` | 수평 정렬 |
| `V` | 수직 정렬(두 개 이상 선택 시) |
| `⌘K` | 자동 정렬 |
| `[` | 텍스트 노드 창 줄이기 |
| `]` | 텍스트 노드 창 키우기 |
| `⇧` + 클릭 또는 드래그 | 선택에 추가 |

## 태그와 패널

| 단축키 | 동작 |
|---|---|
| `⌘B` | 소재 라이브러리 |
| `⌥` + `` ` `` | 참조 선택 모드 전환 |
| `⌘1`–`⌘8` | 선택 항목의 색상 태그 토글 |
| `⌘0` | 선택 항목의 태그 지우기 |
| `⇧1`–`⇧8` | 그 태그의 노드 선택(50개까지) |
| `⌥1`–`⌥8` | 태그로 거르기, 또는 태그된 노드를 선택한 생성 노드에 연결 |
| `⌥0` | 태그 필터 해제 |

## 디렉터 바

디렉터 바에 초점이 있을 때 적용됩니다.

| 단축키 | 동작 |
|---|---|
| `Space` | 재생 / 일시정지 |
| `←` `→` | 이전 / 다음 |
| `↑` | 주 미디어 고르기 |
| `S` | 분할 |
| `Delete` | 클립 삭제 |
| `⌘Z` / `⇧⌘Z` | 실행 취소 / 다시 실행 |
| `⌘` + 스크롤 | 타임라인 확대 |

<Note>
  `V`는 일부러 두 가지 역할을 합니다. 아무것도 선택하지 않았으면 비디오 노드를 만들고, 두 개 이상 선택했으면 수직으로 정렬합니다.
</Note>
