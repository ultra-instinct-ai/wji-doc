## 로컬 도구

브라우저 안에서 돌아가며 크레딧을 쓰지 않습니다.

| 도구 | 노드 | 하는 일 |
|---|---|---|
| **트림** | 비디오, 오디오 | 클립을 짧게 만듭니다 |
| **프레임 캡처** | 비디오 | 정지 이미지를 새 이미지 노드로 뽑습니다 |
| **자르기** | 이미지 | 일반적인 크롭 |
| **주석** | 이미지 | 사각형, 원, 화살표, 선, 텍스트. 레이어 패널 포함 |
| **선명도** | 이미지 | 샤프닝 필터 |
| **빠른 분할** | 이미지 | 이미지를 격자로 잘라 각각의 노드로 만듭니다 |

## 부분 재생성

캔버스에서 가장 유용한 비디오 기능입니다. 클립의 **일부**를 다시 만들어 이어 붙입니다.

<Steps>
  <Step title="구간 고르기">
    비디오 노드에서 바꾸고 싶은 범위를 지정합니다.
  </Step>
  <Step title="대체본 생성">
    WJI가 그 구간을 업로드해 편집 모드로 다시 만듭니다.
  </Step>
  <Step title="네 트랙 검토">
    노드에서 원본, 구간, 생성된 대체본, 이어붙인 결과를 미리 볼 수 있습니다.
  </Step>
  <Step title="이어 붙이기">
    **전체 비디오 이어 붙이기**로 하나로 되돌립니다. 결과는 이어붙인 클립으로, 생성된 구간만으로, 또는 앞뒤를 포함한 배열로 디렉터 바에 추가할 수 있습니다.
  </Step>
</Steps>

부분 편집에는 이를 지원하는 모델이 필요합니다. 상태는 대기 중, 실행 중, 완료, 실패로 진행됩니다.

## AI 비디오 도구

| 도구 | 설명 |
|---|---|
| **뎁스 비디오** | 뎁스 모델이 있어야 합니다 |
| **비디오 업스케일** | 업스케일 생성 노드를 만듭니다 |
| **파노라마 생성** | 이미지를 360° 파노라마로 바꿔 파노라마 뷰어에서 볼 수 있게 합니다 |

계정에 필요한 모델이 없으면 WJI가 조용히 실패하지 않고 어떤 모델이 없는지 알려 줍니다.

## 파노라마 뷰어

파노라마 노드는 전용 뷰어로 열립니다. 더블클릭해도, 툴바를 써도 됩니다. 뷰어는 현재 시점을 JPEG로 내보낼 수 있습니다.
