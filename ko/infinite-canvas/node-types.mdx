## 내용 노드

| 노드 | 담는 것 | 눈여겨볼 동작 |
|---|---|---|
| **텍스트** | Markdown | 더블클릭 편집, AI 도우미, 문서 가져오기, Markdown·일반 텍스트·Word로 다운로드, `[`와 `]`로 창 크기 조절 |
| **표** | 필드 매핑이 있는 행과 열 | 표 편집, AI 도우미, 어느 열이 텍스트이고 어느 열이 프롬프트인지 지정, 다시 업로드 |
| **YouTube** | 임베드된 YouTube 링크 | URL을 붙여 넣으면 만들어집니다. AI 도우미가 요약, 각색, 대본을 텍스트 노드로 만듭니다 |
| **데이터셋** | 워크스페이스 데이터셋 | 소재 보기와 내용 보기 전환, 거기서 이미지·영상 생성, 업로드, 다운로드, 스토리보드 도구 |
| **소재 팩** | 연결로 모은 여러 미디어 | 다운로드, 미리보기, 스토리보드 도구. 구성원은 비활성화·재정렬·이름 변경·제거 가능 |

## 구조와 주석

| 노드 | 용도 |
|---|---|
| **그룹** | 언제나 맨 뒤에 그려지는 시각적 그릇. 끌면 닿아 있는 노드가 함께 움직입니다. 연결은 안 됩니다 |
| **제목** | 글자 크기에 맞춰 상자가 커지는 큰 글씨 |
| **메모** | 포스트잇 |
| **할 일** | 추가·삭제·체크가 되는 목록 |
| **화살표** | 끌 수 있는 두 끝점 |

뒤의 넷은 통틀어 **주석**입니다. 전경색과 배경색 조작을 공유하고, 편집 권한을 주지 않은 채 뷰어에게 추가를 허용할 수 있습니다. [뷰어 접근](/ko/workspaces/viewer-access)을 참고하세요.

<Note>
  그룹 노드는 언제나 다른 노드 뒤에 그려지고 연결에 참여할 수 없습니다. 공간을 정리할 뿐 생성에 의미를 나르지 않습니다.
</Note>
