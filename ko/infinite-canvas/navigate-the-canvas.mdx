## 확대

| 동작 | 방법 |
|---|---|
| 확대·축소 | `⌘` + 스크롤 휠 |
| 확대 | `⌘ =` |
| 축소 | `⌘ -` |
| 핀치 | 트랙패드 핀치. Mac에서는 감도가 더 높습니다 |

확대 범위는 **10%에서 312.5%**입니다. 현재 배율은 왼쪽 아래 뷰포트 제어 바에 보입니다.

<Note>
  브라우저가 페이지 전체를 확대하지 않도록 WJI가 `⌘` + 스크롤을 가로챕니다.
</Note>

## 이동

- **Space + 드래그**
- **마우스 가운데 버튼 드래그**
- **스크롤 휠**로 세로 이동, `Shift` + 스크롤로 가로 이동

노드를 화면 가장자리로 끌면 캔버스가 자동으로 스크롤됩니다.

## 화면 맞추기

| 동작 | 단축키 |
|---|---|
| **모든 노드에 맞추기** | `Shift + Z`, 또는 제어 바의 버튼 |
| **선택 항목으로 확대** | `Tab` 또는 `Z` |

둘 다 튀지 않고 부드럽게 움직입니다. 생성 노드 하나로 확대하면 그 아래의 생성 패널까지 읽을 수 있도록 화면에 포함됩니다.

## 미니맵

<Frame caption="노드 태그 색으로 칠해진 미니맵">
  <img src="/images/infinite-canvas/minimap-01.png" alt="캔버스 모서리에서 여러 태그 색으로 노드 위치를 보여 주는 미니맵" />
</Frame>

제어 바의 지도 아이콘으로 켜고 끕니다. 최대 220×140이며 노드를 색상 태그로 칠하고, 클릭하면 이동합니다.

## 격자

배경은 월드 좌표의 점 격자입니다. 간격은 20 px이며 확대에 맞춰 함께 커집니다. 항상 켜져 있습니다.

<Warning>
  드래그 중 스냅이나 정렬 가이드는 없습니다. WJI의 정렬은 나중에 다중 선택 툴바에서 의도적으로 적용하는 동작이지, 노드를 옮기는 동안 일어나는 일이 아닙니다.
</Warning>

## 성능 모드

번개 아이콘이 **표준**과 **빠름** 렌더링을 전환합니다. 빠름 모드는 연결선과 라벨 장식을 숨기고, 확대가 20% 아래일 때는 연결 핸들도 그리지 않습니다. 무거운 캔버스에서는 부드럽게 움직이느냐 마느냐를 가릅니다.

이 설정은 기억됩니다.

## 뷰포트 기억

확대와 위치가 캔버스마다 기억되므로, 돌아오면 떠났던 자리에서 이어집니다.
