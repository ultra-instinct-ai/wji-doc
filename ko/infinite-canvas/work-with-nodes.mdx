## 선택

| 동작 | 방법 |
|---|---|
| 하나 선택 | 클릭 |
| 선택에 추가 | `Shift` + 클릭, 또는 `⌘` + 클릭 |
| 영역 선택 | 빈 곳에서 드래그. 완전히 감싸지 않아도 **닿은** 것이 선택됩니다 |
| 영역으로 추가 선택 | `Shift` + 드래그 |
| 전체 선택 | `⌘A` |
| 색상 태그로 선택 | `Shift` + `1`–`8` |
| 선택 해제 | `Esc` |

<Warning>
  **전체 선택과 태그 선택 모두 50개 노드가 상한입니다.** 큰 캔버스에서는 전부 잡히지 않습니다. 색상 태그 필터가 켜져 있으면 전체 선택은 그 태그의 노드만 가져옵니다.
</Warning>

선택되지 않은 노드는 마우스를 **뗄 때** 선택됩니다. 누르는 순간이 아니므로 드래그를 시작해도 패널이 뜨지 않습니다.

## 이동과 복제

- 끌면 이동
- **Alt + 드래그**는 복제 — 원본은 제자리에 남습니다. Alt는 다른 여러 끌기의 의미도 바꿉니다. [Alt 키](/ko/infinite-canvas/overview#alt는-끌기의-의미를-바꿉니다)를 보세요
- `⌘D`는 선택한 것을 제자리에 복제
- `⌘C`와 `⌘V`는 복사와 붙여넣기, **복사한 노드 사이의 연결까지 포함**합니다

## 크기 조절

지원하는 노드는 오른쪽 아래에 손잡이가 있습니다. 최소 크기는 그룹 120×80, 텍스트 120×60, YouTube 240×135로 다릅니다. 화살표는 끝점을 끌어 조절합니다.

텍스트 노드는 `[`와 `]`에도 반응해 창을 비례로 조절합니다. 여러 개를 선택하면 그 사이 간격이 유지됩니다.

## 이름 변경

**노드 위의 이름 라벨을 더블클릭**하세요. Enter로 확정, `Esc`로 취소입니다.

## 정렬과 그룹화

정렬은 실시간 가이드가 아니라 한 번의 동작입니다.

| 동작 | 단축키 |
|---|---|
| 수평 정렬 | `H` |
| 수직 정렬 | `V` |
| 자동 정렬 | `⌘K` |

그룹 노드는 선택 영역 둘레에 40 px 여백을 둡니다. 그룹을 끌면 닿은 노드가 함께 따라옵니다.

<Note>
  두 개 이상 선택했을 때 `V`는 "새 비디오 노드"가 아니라 수직 정렬입니다.
</Note>

## 색상 태그

<Frame caption="태그에 이름을 붙인 색상 태그 팝오버">
  <img src="/images/infinite-canvas/color-tag-popover-01.png" alt="여덟 색과 편집 가능한 이름, 태그 지우기 항목이 있는 색상 태그 팝오버" />
</Frame>

여덟 색이며, 각각 캔버스 전체에 걸쳐 이름을 붙일 수 있습니다.

| 동작 | 단축키 |
|---|---|
| 선택 항목의 태그 토글 | `⌘1`–`⌘8` |
| 선택 항목의 태그 지우기 | `⌘0` |
| 그 태그의 노드 선택 | `⇧1`–`⇧8` |
| 태그로 캔버스 거르기 | `⌥1`–`⌥8` |
| 필터 해제 | `⌥0` |

태그는 미니맵 색상, 상단 바 필터, 태그별 일괄 다운로드, 그리고 뷰어가 무엇을 볼 수 있는지를 좌우합니다.

<Tip>
  태그에 이름을 붙이세요. "승인됨", "수정 필요", "고객 공개 가능"이라고 하면 색 구분 습관이 팀 전체가 읽을 수 있는 것이 됩니다. 뷰어 접근의 표시 태그 설정도 그때 비로소 제 일을 합니다.
</Tip>

## 할 수 없는 것

노드 잠금이 없고, 맨 앞·맨 뒤로 보내기도 없습니다. 층위는 고정이며 그룹 노드는 언제나 다른 모든 것의 뒤에 그려집니다.
