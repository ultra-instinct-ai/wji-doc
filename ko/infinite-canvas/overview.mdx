**무한 캔버스**는 노드를 놓고 서로 잇는 보드입니다. 이미지 한 장이 더는 작업 단위가 아닐 때 — 시퀀스를 짜거나, 여러 숏의 일관성을 지키거나, 편집본을 조립할 때 — 쓰는 앱입니다.

  <img src="/images/infinite-canvas/overview-01.png" alt="이미지 노드와 텍스트 노드가 생성 노드로 연결된 무한 캔버스" />
</Frame>

## 중요한 개념은 하나

**연결은 장식이 아닙니다. 맥락이 AI에 닿는 통로입니다.**

이미지 노드를 생성 노드에 이으면 그 이미지가 참조가 됩니다. 텍스트 노드를 이으면 그 내용이 프롬프트 앞에 붙습니다. 데이터셋을 이으면 구성원이 펼쳐집니다.

이것이 이해되면 나머지는 따라옵니다. 다른 무엇보다 [연결과 참조](/ko/infinite-canvas/connections-and-references)를 먼저 읽으세요.

## 화면에 있는 것

<Frame caption="캔버스 구성 요소: 캡슐 툴바, 상단 바, 뷰포트 제어 바">
  <img src="/images/infinite-canvas/chrome-01.png" alt="왼쪽 캡슐 툴바, 위쪽 상단 바, 왼쪽 아래 뷰포트 제어 바를 표시한 캔버스" />
</Frame>

| 영역 | 담긴 것 |
|---|---|
| 왼쪽 **캡슐 툴바** | 만들기, 소재 라이브러리, 생성 기록, 디렉터 바, 설정, 단축키 |
| **상단 바** | 색상 태그 필터, 캔버스 전환기, 검색, 캔버스 설정 |
| 왼쪽 아래 **뷰포트 제어 바** | 실행 취소/다시 실행, 확대, 맞춤, 미니맵, 성능 모드 |
| 아래쪽 **디렉터 바** | 클립을 배열하는 타임라인. 캡슐 툴바에서 엽니다 |
| 왼쪽 위 **저장 상태** | 대기 중, 저장 중, 저장됨, 저장 실패 |

캔버스를 열면 워크스페이스의 왼쪽 패널이 좁은 레일로 접히고, 캔버스에 있는 동안 계속 접혀 있습니다.

## Alt는 끌기의 의미를 바꿉니다

Alt — Mac에서는 **Option** — 는 일찍 익혀 둘 만한 보조 키입니다. 누르지 않으면 끌기는 **이동**이지만, 누른 채로는 같은 동작이 **보관, 복제, 팬아웃**이 됩니다. 무엇을 잡았느냐에 따라 다르게 동작하므로 모든 경우를 한자리에서 보는 편이 좋습니다.

### Alt + 끌기

| Alt를 누른 채 끌기 | 놓는 곳 | 결과 |
|---|---|---|
| 노드 하나 | 캔버스 어디든 | **복제**합니다. 원본은 제자리에 남습니다 |
| 노드의 `+` 핸들 | 선택한 여러 노드 | **팬아웃** — 소스마다 새 노드 하나씩, 일대일 |
| 미디어 또는 텍스트 노드 | **데이터셋 노드** | 그 데이터셋에 넣습니다 |
| 미디어 또는 텍스트 노드 | **소재 라이브러리의 데이터셋** | 거기에 넣습니다 |
| 미디어 또는 텍스트 노드 | **라이브러리 카드 사이의 틈** | 그 자리에 새 데이터셋을 만듭니다 |
| 미디어 노드 | **디렉터 바** | 클립을 추가하거나 기존 클립의 주 미디어로 지정합니다 |
| **데이터셋 노드 안의 썸네일** | 다른 데이터셋 노드 | 데이터셋 사이로 소재를 옮깁니다 |
| **데이터셋 노드 안의 썸네일** | 빈 캔버스 | 그것으로 미디어 노드를 만듭니다 |
| **소재 라이브러리**의 소재 | 캔버스 | 그것으로 노드를 만듭니다 |

<Note>
  Alt가 의미를 갖지 않는 곳에 놓으면 WJI가 조용히 실패하지 않고 유효한 대상이 어디인지 알려 줍니다.
</Note>

### Alt + 키

| 단축키 | 하는 일 |
|---|---|
| `⌥` + `I` / `V` / `A` | 하나가 아니라 선택한 **각각의** 노드에서 일대일로 생성합니다 |
| `⌥` + `1`–`8` | 태그로 거르기 — 생성 노드를 선택한 상태라면 그 태그를 가진 노드를 모두 연결합니다 |
| `⌥` + `0` | 태그 필터 해제 |
| `⌥` + `` ` `` | 참조 선택 모드 전환 |

Alt를 누르면 다음 끌기의 동작이 달라지는 경우, 다중 선택 툴바에 `⌥` 배지가 뜹니다. 어떤 동작이 두 가지 뜻을 갖는지 외울 필요가 없습니다.
