## 여섯 가지 진입점

<Frame caption="만들기 패널">
  <img src="/images/infinite-canvas/create-panel-01.png" alt="캔버스에 놓을 수 있는 모든 노드 종류를 나열한 만들기 패널" />
</Frame>

<Steps>
  <Step title="빈 곳 더블클릭">
    그 자리에 만들기 메뉴가 열립니다. 빈 캔버스의 안내도 그렇게 말합니다.
  </Step>
  <Step title="빈 곳 우클릭">
    **업로드**, **노드 만들기**, **붙여넣기**가 나옵니다.
  </Step>
  <Step title="만들기 버튼">
    캡슐 툴바의 첫 아이콘입니다. 만들기 패널이 열리고, 종류를 클릭하면 보이는 화면의 가운데에 놓입니다.
  </Step>
  <Step title="연결 핸들에서 끌기">
    노드의 `+` 핸들을 빈 곳으로 끌고 놓습니다. 나타나는 메뉴는 **이미 연결된** 새 노드를 만듭니다.
  </Step>
  <Step title="키보드">
    `I`, `V`, `A`가 포인터 위치에 이미지, 비디오, 오디오 생성 노드를 만듭니다. 무언가 선택되어 있으면 새 노드가 자동으로 그것에 연결됩니다.
  </Step>
  <Step title="끌기, 붙여넣기, 업로드">
    아래의 **파일을 캔버스에 올리기**를 보세요.
  </Step>
</Steps>

## 만들기 메뉴에 있는 것

<Frame caption="빈 곳을 더블클릭해 연 만들기 메뉴">
  <img src="/images/infinite-canvas/create-menu-01.png" alt="캔버스의 메뉴로, 구분선 위에 미디어 종류가, 아래에 주석 하위 메뉴가 있음" />
</Frame>

전체 메뉴에는 미디어 종류 — 텍스트, 표, 이미지, 파노라마, 비디오, 오디오, 데이터셋, 소재 팩, 그룹 — 이 나오고, 구분선 뒤에 제목·메모·할 일·화살표가 든 **주석** 하위 메뉴가 있습니다.

`+` 핸들에서 끌면 목록이 짧아집니다. 연결 대상으로 말이 되지 않는 것이 있기 때문입니다. 데이터셋과 그룹은 빠집니다. 출발점이 소재가 있는 이미지 노드라면 파노라마가 더해집니다. **더 보기** 하위 메뉴에는 설명, 스토리보드, 뎁스 비디오, 비디오 업스케일, 이미지에서 스케치, 캐릭터 시트가 들어 있습니다.

## 파일을 캔버스에 올리기

파일을 어딘가에 먼저 올려 둘 필요가 없습니다. 보드에 떨어뜨리면 WJI가 그게 무엇인지 알아냅니다.

### 네 가지 방법

<Steps>
  <Step title="바탕화면에서 끌어오기">
    하나든 여럿이든 보드 어디에나 떨어뜨리세요. 각각이 떨어뜨린 자리에서 노드가 됩니다.
  </Step>
  <Step title="붙여넣기">
    `⌘V`는 클립보드의 이미지, 스프레드시트 파일, 표 형태의 텍스트, 일반 텍스트를 받습니다.
  </Step>
  <Step title="빈 곳 우클릭">
    **업로드**를 고르고 파일을 선택합니다.
  </Step>
  <Step title="노드의 업로드 버튼">
    이미지, 비디오, 오디오, 데이터셋 노드는 각각 툴바에 업로드 기능이 있어, 이미 있는 노드에 파일을 넣을 수 있습니다.
  </Step>
</Steps>

### 파일 종류별로 무엇이 되나

| 이것을 떨어뜨리면 | 이렇게 됩니다 |
|---|---|
| 이미지 파일 | **이미지** 노드 |
| 비디오 파일 — `mp4`, `mov`, `webm`, `m4v`, `mkv`, `avi` | **비디오** 노드 |
| 오디오 파일 — `mp3`, `wav`, `m4a`, `aac`, `ogg`, `flac`, `opus`, `weba`, `webm` | **오디오** 노드 |
| CSV나 스프레드시트 파일 | **표** 노드. 여러 개면 아래로 쌓입니다 |
| Markdown이나 텍스트 문서 | **텍스트** 노드 |
| 텍스트로 붙여 넣은 YouTube 링크 | **YouTube** 노드 |

이미지는 확장자가 아니라 형식으로 인식하므로, 브라우저가 이미지로 다루는 것이면 됩니다.

<Warning>
  업로드 상한은 이미지·오디오·문서가 **25 MB**, 비디오가 **200 MB**입니다. 참조 비디오에 적용되는 더 빡빡한 제한을 포함한 전체 내용은 [지원 파일 형식](/ko/reference/supported-file-types)을 보세요.
</Warning>

파일이 아니라 이미 있는 **소재**를 끌어와도 — 소재 라이브러리, 생성 기록, 앱의 다른 곳 어디서든 — 노드가 만들어집니다. 그것을 포함한 모든 끌기 동작은 [끌어다 놓기](/ko/image-generation/drag-and-drop)에 정리되어 있습니다.

## 붙여넣기

캔버스에서 `⌘V`는 다음 순서로 내용을 처리합니다.

1. **이미지 파일이나 이미지 URL** → 업로드해서 이미지 노드로
2. **스프레드시트 파일** → 테이블 노드
3. **표 형태의 텍스트**(TSV나 CSV) → 테이블 노드
4. **일반 텍스트** → YouTube 링크면 YouTube 노드, 아니면 텍스트 노드
5. **앞서 복사한 노드** → 연결까지 함께 붙여넣기

마우스를 움직였다면 포인터 자리에, 아니면 직전 붙여넣기에서 살짝 어긋난 자리에 놓입니다.

## 표의 행이 노드가 됩니다

**테이블 노드**에서 연결을 끌어내 테이블이 아닌 노드를 만들면 **행마다 연결된 노드 하나**가 만들어집니다. 숏 리스트를 생성 노드 묶음으로 바꾸는 가장 빠른 길입니다.

<Tip>
  숏 리스트를 표로 붙여 넣고 프롬프트가 든 열을 매핑한 뒤 표 밖으로 끌어내세요. 모든 행이 각자의 생성 노드로 도착하며, 연결도 프롬프트도 이미 갖춘 상태입니다.
</Tip>
