## 生成の失敗

生成が失敗すると、WJI はプロバイダのエラーコードではなく平易な理由を表示します。全部で 33 種類あり、以下は対処法ごとにまとめたものです。

### 内容がブロックされた

| メッセージ | 対処 |
|---|---|
| **実在の人物が含まれています** | 参照画像に実在の人物が写っています。差し替えてください |
| **プロンプトが安全ではありません** | より中立的な表現に言い換えてください |
| **動画／音声／画像の内容が制限されました** | *出力*が制限に触れました。プロンプトを調整してください |
| **安全ポリシーに触れました** | 参照か出力のどちらかです。分からなければ両方直してください |
| **禁止された内容が含まれます** | 画像を作れませんでした。プロンプトか参照を調整してください |
| **著作権に関わる可能性があります** | プロンプトか参照素材を変えてください |
| **出力音声が著作権に関わる可能性があります** | プロンプト、台詞、参照音声を調整してください |

内容のブロックは WJI ではなくモデル提供元が判断します。再試行より言い換えのほうが効きます。

### 参照素材が適切でない

| メッセージ | 対処 |
|---|---|
| **参照画像が小さすぎます** | 短辺が **300 px** 以上必要です |
| **音声が長すぎます** | 短くしてください。Seedance は通常 15 秒以下です |
| **音声が短すぎます** | Seedance 2.0 の参照音声は通常 1.8 秒以上必要です |
| **音声形式が非対応です** | 変換してください |
| **動画の尺が不正です** | モデルの要件を確認してください |
| **編集用動画の尺が範囲外です** | 動画編集には **4〜30 秒**の参照クリップが必要です |
| **解像度が低すぎます** | もっと高解像度の参照動画を使ってください |
| **参照素材がありません** | 参照画像か参照動画を少なくとも 1 つ追加してください |
| **参照が競合しています** | 音声生成は参照画像と参照音声を同時に使えません。片方だけにしてください |

### プロンプトに問題がある

| メッセージ | 対処 |
|---|---|
| **プロンプトがありません** | 入力してください |
| **プロンプトが短すぎます** | 記述を足してください |
| **プロンプトがタスクの種類と合いません** | 生成モードのプロンプトに編集や延長の語が入っています。タスクの種類を変えるか、言い換えてください |
| **編集の意図がありません** | 編集モードには *edit*、*add*、*remove*、*replace* のような語が必要です |
| **延長の意図がありません** | 延長モードには *extend* や *continue* のような語が必要です |
| **タスクの種類が合いません** | タスクの種類、画面比率、尺、プロンプトを合わせて確認してください。編集と延長には自動比率と参照動画が必要です |

### 何も返ってこない

| メッセージ | 対処 |
|---|---|
| **画像が生成されませんでした** | プロンプトか参照を調整して再試行してください |
| **モデルから結果がありません** | 同上 |
| **生成がタイムアウトしました** | しばらくしてから再試行してください |

### サービス側の問題

| メッセージ | 対処 |
|---|---|
| **サービスエラー** | 一時的なものです。少し待って再試行してください |
| **割り当てを使い切りました** | あなたのクレジットではなくプロバイダの容量です。後で試してください |
| **ネットワークエラー** | 接続を確認して再試行してください |
| **無効なリクエスト**／**無効なパラメータ** | プロンプトと参照を確認してください |
| **生成に失敗しました** | 該当するものがないときの汎用メッセージ |

## その他のよくある問題

**「素材 ID を解決できません。先に画像を素材ライブラリに追加してください」** — WJI が識別できない画像をドラッグしました。素材ライブラリに保存してから、そこからドラッグしてください。

**生成中だが止めたい** — 止められません。キャンセルはありません。完了か失敗を待ってください。

**モデルを切り替えたら参照が消えた** — 新しいモデルが受け付ける数が少ないため、古いものが削られました。[モデルを選ぶ](/ja/image-generation/models)を参照してください。

**頼んでいないのに結果がスタイライズされる** — スタイルプリセットが選ばれたままです。プロンプト欄に出ないまま最終プロンプトへ追加されます。[プロンプトを書く](/ja/image-generation/prompts)を参照してください。

**削除したものを元に戻せない** — 元に戻すの対象を確認してください。作成、貼り付け、複製、アップロード、生成結果は対象外で、キャンバスを切り替えると履歴も消えます。[自動保存と元に戻す](/ja/infinite-canvas/autosave-and-undo)を参照してください。

**サブスクリプションをアップグレードできない** — アップグレードの導線はありません。解約し、期間の終了を待ってから希望のプランを申し込んでください。[サブスクリプション](/ja/billing/subscriptions)を参照してください。

**「ワークスペースが合計／月間の上限に達しました」** — 支出の上限が設定されています。[ワークスペース設定](/ja/workspaces/settings)を参照してください。

**「この組織のメンバーではありません」または「組織が停止されています」** — 自動的に個人スペースへ戻されます。[身元を切り替える](/ja/organizations/switching-context)を参照してください。

**組織からメンバーを外せない** — その人がまだワークスペースの予算責任者です。先に付け替えてください。

**共有した招待リンクを止めたい** — ワークスペースのリンクは取り消せますが、組織の招待は取り消せず、7 日で期限切れになります。
