## キャンバス

| 制限 | 値 |
|---|---|
| ズーム範囲 | 10% から 312.5% |
| すべて選択 | **50 ノード** |
| カラータグで選択 | **50 ノード** |
| 元に戻す深さ | **40 ステップ**。セッション限りで、キャンバス切り替えで消えます |
| カラータグ | 8 色 |
| グリッド間隔 | 20 px |
| 自動保存 | 手を止めて約 1.5 秒後、連続編集時は最長 3 秒 |

ノードの最小サイズ: グループ 120×80、テキスト 120×60、YouTube 240×135。

## 生成

| 制限 | 決めるもの |
|---|---|
| 参照画像・動画・音声の数 | モデル |
| 生成枚数 | モデル |
| 動画の尺 | モデルの最小・最大・刻み |
| 画面比率 | モデル |

参照の上限を超えると新しいものが残り、**古いものが一覧の先頭から削られます**。

## デジタル司会者

| 制限 | 値 |
|---|---|
| 番組名 | 80 文字 |
| セグメントの長さ | 15 秒か 30 秒。他の選択肢はありません |
| セグメント動画の尺 | 5〜60 秒 |
| 話速 | -50〜100 |

## ワークスペースの支出

ワークスペースには**合計**と**月間**の上限をクレジット単位で設定できます。どちらも未設定にできます。月間の上限は暦月の 1 日にリセットされます。

事前に費用を見積もれない機能では、上限を**ちょうど**使い切ったワークスペースは新しい作業を開始できません。
