## アップロードのサイズ上限

| 種類 | 上限 |
|---|---|
| 画像、音声、文書 | **25 MB** |
| 動画 | **200 MB** |

## 参照動画

参照動画には通常のアップロードより厳しい制限があり、長さによって変わります。

| 長さ | 最大サイズ |
|---|---|
| 15 秒まで | **50 MB** |
| 15〜30 秒 | **200 MB** |

| 制約 | 値 |
|---|---|
| 最短の尺 | 2 秒 |
| 最長の尺 | 30 秒 |
| 寸法 | 各辺 300〜6000 px |
| アスペクト比 | 0.4〜2.5 |
| 解像度 | 1920×1080 まで |
| 既定の本数 | モデルの指定がなければ 3 本 |

<Warning>
  WJI が動画の尺を読み取れない場合、実際の長さに関係なくサイズ上限は **50 MB** になります。エンコードし直すとたいてい解決します。
</Warning>

対応する動画の拡張子: `mp4`、`mov`、`webm`、`m4v`、`mkv`、`avi`。参照動画については **MP4 と MOV** を受け付けます。

## 参照画像

| 制約 | 値 |
|---|---|
| 短辺の最小 | **300 px** |
| 1 枚あたりの上限 | Vertex プロトコルのモデルで 20 MB |
| 枚数 | モデルが決めます |

## 参照音声

要件はモデルによって異なります。Seedance のモデルは **1.8〜15 秒**を想定しています。

## 文書

| 機能 | 受け付ける形式 |
|---|---|
| Build with AI、アイデア作成 | `.docx`、`.pdf`、`.txt`、`.md`、画像 |
| デジタル司会者の台本 | `.txt`、`.md`、`.docx`。`.doc` は**不可** |
| キャンバスのテキストノード取り込み | Markdown とテキスト文書 |
| キャンバスのテーブルノード | CSV と表計算ファイル |

## ワークスペースのアバター

JPG と PNG。

## ダウンロード

| ダウンロード | 形式 |
|---|---|
| 単一の素材 | 元のファイル |
| フォルダ、データセット、複数選択 | ZIP。フォルダ構造を保持します |
| キャンバスのテキストノード | Markdown、プレーンテキスト、Word |
| ディレクターバーの動画 | MP4 |
| ディレクターバーのプロジェクト | `timeline.otio`、`timeline.edl`、`media/`、`manifest.json` を含む ZIP |
| デジタル司会者の履歴 | CSV |
