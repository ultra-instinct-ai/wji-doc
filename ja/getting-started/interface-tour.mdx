## 上部ナビゲーション

ワークスペース以外のすべてのページは同じヘッダーを共有します。

<Frame caption="WJI の上部ナビゲーション">
  ![チャット、ワークスペース、エージェント、画像クリエイターのリンクと右側のアカウント操作を表示した WJI の上部ナビゲーションバー](/images/Screenshot-2026-09-03-at-15.50.36.png)
</Frame>

| リンク | 開く場所 |
| --- | --- |
| **チャット** | ワークスペースに属さない、エージェントとの会話 |
| **ワークスペース** | ワークスペース一覧 — 多くの作業はここから始まります |
| **エージェント** | エージェントを探し、自分が作ったものを管理します |
| **画像クリエイター** | ワークスペースに紐づかない単独の生成ツール |

さらに 2 つのリンクは一部のアカウントにのみ表示されます。**IP/キャラクター**は素材グループの権限が必要で、**管理**は管理者にのみ表示されます。

ヘッダー右側には、テーマ切り替え、言語切り替え、実行中の生成を追うタスクトラッカー、通知ベル、プロフィールメニューが並びます。プロフィールメニューには**ダッシュボード**、**利用状況**、**請求履歴**、**サポート**、組織の切り替えも含まれます。

## ワークスペース一覧

**ワークスペース**を開くと**マイワークスペース**が表示されます。各カードにはカバー、画面比率、言語、メンバー、最終更新日時が表示されます。カードの星をクリックするとお気に入りに追加できます。

カードの上では次の操作ができます。

- **すべて**、**自分の**、**共有された**、**お気に入り**で絞り込む
- 更新日時または作成日時で、昇順・降順に並べ替える
- キーワードで検索する
- **ワークスペースを作成**をクリックする

ワークスペースを開くと画面全体が 3 カラムのレイアウトに切り替わります。

上部の**アプリバー**には、一覧に戻る矢印、ワークスペース名、そして閲覧権限がある場合はワークスペースの残高を示すクレジットバッジがあります。

**左パネル**はアプリを切り替える場所です。ワークスペースには既定で 3 つ表示されます。

  <Card title="アイデア画像生成" icon="image" href="/ja/image-generation/overview">

  <Card title="無限キャンバス" icon="diagram-project" href="/ja/infinite-canvas/overview">

アプリアイコンの下にはツールバーとファイルツリーがあり、内容は選んだアプリによって変わります。このパネルにはタスクトラッカーと設定の歯車もあります。右端をドラッグして幅を変えたり、細いレールに折りたたんだりできます。

<Note>
  無限キャンバスを開くと左パネルは自動的にレールに折りたたまれ、キャンバスにいる間は展開できません。
</Note>

**メイン領域**には選択したアプリが表示されます。**右パネル**はワークスペースを対象とした AI チャットで、アイデアツールでは表示されますが、キャンバスでは表示されません。

## 初回の訪問

ワークスペースを初めて開くと、短いチュートリアルがレイアウトを案内します。閉じることができ、チェックボックスをオンにすればそのワークスペースでは次回から自動表示されません。
