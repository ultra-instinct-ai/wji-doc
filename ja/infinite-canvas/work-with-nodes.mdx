## 選択

| 操作 | 方法 |
|---|---|
| 1 つ選ぶ | クリック |
| 追加選択 | `Shift` + クリック、または `⌘` + クリック |
| 範囲選択 | 空いている場所をドラッグ。囲みきらなくても**触れた**ものが選ばれます |
| 範囲で追加選択 | `Shift` + ドラッグ |
| すべて選択 | `⌘A` |
| カラータグで選択 | `Shift` + `1`–`8` |
| 選択解除 | `Esc` |

<Warning>
  **すべて選択とタグ選択はどちらも 50 ノードが上限です。** 大きなキャンバスでは全部は取れません。カラータグのフィルタが有効なら、すべて選択はそのタグのノードだけを対象にします。
</Warning>

未選択のノードはマウスを**離した**ときに選ばれます。押した瞬間ではないため、ドラッグを始めてもパネルは開きません。

## 移動と複製

- ドラッグで移動
- **Alt + ドラッグ**で複製。元のノードはその場に残ります
- `⌘D` で選択範囲をその場に複製
- `⌘C` と `⌘V` でコピーと貼り付け。**コピーしたノード同士の接続も含みます**

## サイズ変更

対応するノードは右下にハンドルがあります。最小サイズはそれぞれ異なり、グループ 120×80、テキスト 120×60、YouTube 240×135 です。矢印は端点をドラッグして変えます。

テキストノードは `[` と `]` にも反応し、ウィンドウを等比で拡縮します。複数選択しているときは、間隔が保たれます。

## 名前の変更

**ノード上部の名前ラベルをダブルクリック**します。Enter で確定、`Esc` で取り消しです。

## 整列とグループ化

整列はガイドではなく、一度きりの操作です。

| 操作 | ショートカット |
|---|---|
| 水平に整列 | `H` |
| 垂直に整列 | `V` |
| 自動整列 | `⌘K` |

グループノードは選択範囲の周囲に 40 px の余白を取ります。グループをドラッグすると、触れているノードも一緒に動きます。

<Note>
  2 つ以上のノードを選んでいるとき、`V` は「新規動画ノード」ではなく垂直整列になります。
</Note>

## カラータグ

<Frame caption="タグに名前を付けたカラータグのポップオーバー">
  <img src="/images/infinite-canvas/color-tag-popover-01.png" alt="8 色と編集可能な名前、タグを消す項目を並べたカラータグのポップオーバー" />
</Frame>

8 色あり、それぞれキャンバス全体で名前を付けられます。

| 操作 | ショートカット |
|---|---|
| 選択範囲のタグを切り替え | `⌘1`–`⌘8` |
| 選択範囲のタグを消す | `⌘0` |
| そのタグのノードを選ぶ | `⇧1`–`⇧8` |
| タグでキャンバスを絞る | `⌥1`–`⌥8` |
| 絞り込みを解除 | `⌥0` |

タグはミニマップの色、上部バーのフィルタ、タグ単位の一括ダウンロード、そして閲覧者に何を見せるかを左右します。

<Tip>
  タグに名前を付けてください。「承認済み」「要修正」「クライアント公開可」とすれば、色分けの習慣がチーム全員に読めるものになります。閲覧者アクセスの表示タグ設定も、そこで初めて実際に働きます。
</Tip>

## できないこと

ノードのロックはなく、最前面・最背面への移動もありません。重なりは固定で、グループノードは常に他のすべての背面に描かれます。
