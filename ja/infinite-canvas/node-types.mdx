## メディアノード

<Columns cols={2}>
  <Card title="画像" icon="image">
    画像素材、またはそれを生成するノード。キャンバスで最も充実したツールバーです。切り抜き、鮮明度、画像編集、絵コンテツール、生成プリセット、履歴、説明、ライブラリへの保存、ダウンロード。
  </Card>
  <Card title="動画" icon="video">

  </Card>
  <Card title="音声" icon="waveform">
    音声ファイル。トリム、生成履歴、説明、ダウンロード。
  </Card>
  <Card title="パノラマ" icon="panorama">
    360° 画像。ダブルクリックまたはツールバーからパノラマビューアを開きます。
  </Card>

## コンテンツノード

| ノード | 保持するもの | 主な操作 |
|---|---|---|
| **テキスト** | Markdown | ダブルクリックで編集、AI アシスタント、文書の取り込み、Markdown / プレーンテキスト / Word でのダウンロード、`[` と `]` でのウィンドウ拡縮 |
| **表** | 列マッピング付きの行と列 | 表の編集、AI アシスタント、どの列がテキストでどの列がプロンプトかの指定、再アップロード |
| **YouTube** | 埋め込まれた YouTube リンク | URL を貼り付けると作られます。AI アシスタントが要約・書き換え・台本をテキストノードとして生成します |
| **データセット** | ワークスペースのデータセット | 素材ビューと内容ビューの切り替え、そこからの画像・動画生成、アップロード、ダウンロード、絵コンテツール |
| **素材パック** | 接続で集めた複数のメディア | ダウンロード、プレビュー、絵コンテツール。メンバーは無効化・並べ替え・改名・削除ができます |

## 構造と注釈

| ノード | 用途 |
|---|---|
| **グループ** | 常に最背面に描かれる視覚的な入れ物。ドラッグすると触れているノードも動きます。接続はできません |
| **タイトル** | 文字サイズに合わせて枠が変わる大きな文字 |
| **メモ** | 付箋 |
| **ToDo** | 追加・削除・チェックができるリスト |
| **矢印** | ドラッグできる 2 つの端点 |

後ろの 4 つはまとめて**注釈**です。前景色と背景色の操作を共有し、編集権限を与えないまま閲覧者に追加を許可できます。[閲覧者のアクセス](/ja/workspaces/viewer-access)を参照してください。

<Note>
  グループノードは常に他のノードの背面に描かれ、接続には参加できません。空間を整理するためのもので、生成に意味を運びません。
</Note>
