カプセルツールバーのはてなマークを押すと、アプリ内でもこの一覧を見られます。表記は Mac のキーです。Windows では `⌘` を `Ctrl` に読み替えてください。

## ノード

| ショートカット | 動作 |
|---|---|
| `I` | 画像生成ノードを作成 |
| `V` | 動画生成ノードを作成 |
| `A` | 音声生成ノードを作成 |
| `/` | プロンプトプリセットからテキストノードを作成 |
| `⌥` + `I` / `V` / `A` | 選択した各ノードから 1 対 1 で生成 |
| 空いている場所をダブルクリック | 作成メニュー |
| テキストノードをダブルクリック | 編集 |
| `⌘ ↵` | テキスト編集を確定 |
| `⌥` + ドラッグ | ノードを複製、またはデータセットへ入れる |
| `+` をドラッグ | 複数選択から接続 |
| `⌥` + `+` をドラッグ | 複数選択からファンアウト |

## 編集

| ショートカット | 動作 |
|---|---|
| `⌘Z` | 元に戻す |
| `⌘⇧Z`（Windows は `Ctrl+Y`） | やり直し |
| `⌘C` | コピー |
| `⌘V` | 貼り付け |
| `⌘D` | 複製 |
| `⌫` または `Del` | 削除 |
| `Esc` | 取り消し、または選択解除 |
| `⌘A` | すべて選択（50 ノードまで） |
| `⌘G` | グループ化 |

## ビューポート

| ショートカット | 動作 |
|---|---|
| `Space` + ドラッグ | パン |
| マウス中ボタンのドラッグ | パン |
| ホイール | 縦にパン。`Shift` + ホイールで横 |
| `⌘` + ホイール | ズーム |
| `⌘ =` | 拡大 |
| `⌘ -` | 縮小 |
| `⇧Z` | すべてのノードに合わせる |
| `Tab` または `Z` | 選択範囲にズーム |
| `H` | 水平に整列 |
| `V` | 垂直に整列（2 つ以上選択時） |
| `⌘K` | 自動整列 |
| `[` | テキストノードのウィンドウを縮小 |
| `]` | テキストノードのウィンドウを拡大 |
| `⇧` + クリックまたはドラッグ | 追加選択 |

## タグとパネル

| ショートカット | 動作 |
|---|---|
| `⌘B` | 素材ライブラリ |
| `⌥` + `` ` `` | 参照選択モードの切り替え |
| `⌘1`–`⌘8` | 選択範囲のカラータグを切り替え |
| `⌘0` | 選択範囲のタグを消す |
| `⇧1`–`⇧8` | そのタグのノードを選択（50 まで） |
| `⌥1`–`⌥8` | タグで絞る、またはタグ付きノードを選択中の生成ノードへ接続 |
| `⌥0` | タグの絞り込みを解除 |

## ディレクターバー

ディレクターバーにフォーカスがあるときに有効です。

| ショートカット | 動作 |
|---|---|
| `Space` | 再生 / 一時停止 |
| `←` `→` | 前 / 次 |
| `↑` | 主メディアを選ぶ |
| `S` | 分割 |
| `Delete` | クリップを削除 |
| `⌘Z` / `⇧⌘Z` | 元に戻す / やり直し |
| `⌘` + ホイール | タイムラインをズーム |

<Note>
  `V` は意図的に二役です。何も選んでいなければ動画ノードを作り、2 つ以上選んでいれば垂直に整列します。
</Note>
