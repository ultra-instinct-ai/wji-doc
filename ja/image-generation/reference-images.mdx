参照は、100 カットにわたって同じ人物に見せ続けるための手段です。一貫性という点では、プロンプトの言い回しより効きます。

## 追加する 6 つの方法

<Steps>
  <Step title="ファイルを選ぶ">
    クリックして選択します。複数選択できます。
  </Step>
  <Step title="ドラッグまたは貼り付け">
    プロンプト欄にファイルを落とすか貼り付けます。この経路は画像のみ受け付けます。
  </Step>
  <Step title="データセットから">
    ワークスペースのアイデアから選びます。キャラクター、ロケーション、衣装、小道具、スタイルでグループ分けされています。
  </Step>
  <Step title="IP 素材から">
    バーチャルキャラクター素材の専用タブです。
  </Step>
  <Step title="生成結果から">
    履歴の結果にカーソルを合わせ、そのまま参照として追加します。
  </Step>
  <Step title="最近使ったもの">
    直近 6 件の参照がワンクリックで使えます。
  </Step>
</Steps>

## 参照の種類

<Frame caption="種類を設定した参照画像">
  ![キャラクター、ロケーション、スタイルなどの種別ラベルが付いた参照カードの並び](/images/Screenshot-2026-09-03-at-17.41.49.png)
</Frame>

すべての参照に種類があります。カードをクリックして設定します。

| 種類 | 用途 |
|---|---|
| **キャラクター** | 人物 |
| **ロケーション** | 場所とセット |
| **衣装** | 服装 |
| **小道具** | 物 |
| **スタイル** | 質感やトーン |
| **レイアウト** | 構図 |
| **その他** | それ以外 |

データセットから引いた参照は種類を自動で引き継ぎます。アイデアの種類を正確に保つべき理由がここにもあります。

参照には名前も付けられます。既定は `image1`、`image2` で、プロンプト内で `@` で指す名前でもあります。

## 上限

**参照の上限枚数を決めるのは WJI ではなくモデルです。** 超えると新しい参照が末尾に追加され、古いものが先頭から削られます。

Vertex プロトコルのモデルは、参照画像 1 枚あたり 20 MB までです。

## 参照動画と参照音声

動画モードでは参照動画と参照音声も追加できます。

| 制約 | 値 |
|---|---|
| 形式 | MP4 または MOV |
| 既定の上限 | 3 本 |
| 尺 | 2〜15 秒、一部のモデルでは 30 秒まで |
| ファイルサイズ | 15 秒までは 50 MB、15〜30 秒は 200 MB |
| 寸法 | 各辺 300〜6000 px |
| アスペクト比 | 0.4〜2.5 |
| 解像度 | 1920×1080 まで |

<Warning>
  WJI が動画の尺を読み取れない場合、実際の長さに関わらずサイズ上限は 50 MB になります。
</Warning>

## ウェイト

**参照ウェイト**のスライダーは 1 つで、すべての参照にまとめて効きます。画像ごとに個別のウェイトはありません。Midjourney 系のモデルは、モデル固有の設定に画像ウェイトとスタイル参照ウェイトを別に持ちます。

## キャンバスでは

無限キャンバスはアップロード一覧を使いません。参照は**接続**から来ます。画像・動画・音声のノードを生成ノードに繋ぐと、それが参照になります。[接続と参照](/ja/infinite-canvas/connections-and-references)を参照してください。
