## 結果を保存先に入れる

<Frame caption="移動先のデータセットを選ぶ">
  <img src="/images/image-generation/move-to-dialog-01.png" alt="素材の移動やコピー先のデータセットを選ぶツリー形式の選択" />
</Frame>

| 操作 | 場所 | 内容 |
|---|---|---|
| **Idea に保存** | 結果メニュー（ワークスペースのみ） | 現在のアイデアに素材を紐づけます |
| **Idea のカバーに設定** | 結果メニュー | そのアイデアのカバー画像にします |
| **画像からアイデアを作成** | 結果メニュー | この画像を持つ新しいアイデアを作ります |
| **素材ライブラリに保存** | キャンバスのノードツールバー | キャンバスノードの素材をデータセットへ入れます |
| **移動** | 素材メニュー | データセット間を移動します。元からは外れます |
| **コピー** | 素材メニュー | 元を残したまま追加先にも入れます |

**移動**と**コピー**はツリー形式の選択画面で保存先のデータセットを選びます。どちらも複数選択に対応し、何件移動・コピーしたかを報告します。

<Note>
  移動した素材が元データセットのカバーだった場合、別の画像が自動でカバーに昇格します。
</Note>

## プレビュー

<Frame caption="素材プレビューのダイアログ">
  <img src="/images/image-generation/asset-preview-01.png" alt="画像、生成の詳細を表示する情報パネル、コメントタブを備えた素材プレビューのダイアログ" />
</Frame>

6 種類のプレビューがあり、それぞれ向いている用途が違います。

| プレビュー | 開き方 | 向いている用途 |
|---|---|---|
| **ライトボックス** | 画像をクリック | ざっと見る、矢印キーで送る、拡大 |
| **素材プレビューダイアログ** | 目のアイコン、サムネイル、履歴 | 情報、生成の詳細、コメント、再利用まですべて |
| **データセットプレビュー** | キャンバスのデータセットノード | 一式の確認と並べ替え、項目のその場編集 |
| **バンドルプレビュー** | キャンバスのバンドルノード | メンバーの有効化・無効化・名前変更・並べ替え |
| **パノラマビューア** | パノラマノード | 360° 表示 |
| **ギャラリービュー** | アイデアの詳細 | キーボードで送る全画面閲覧 |

<Warning>
  ライトボックスは画像専用です。動画は意図的に使いません。クリックが再生ではなくダウンロードになってしまうためです。
</Warning>

よく理解しておく価値があるのは**素材プレビューダイアログ**です。基本情報、ファイルの詳細、生成の詳細一式、コピーボタン付きの 2 種類のプロンプト、使用した参照、タグ、コメント、いいね、その場での名前変更、そして**再生成に使用**を備えます。

## 並べ替え

ドラッグでの並べ替えに対応する一覧が 9 つあり、保存先はそれぞれ異なります。

| 一覧 | 保存先 |
|---|---|
| サイドバーのデータセット | そのフォルダの子の順序 |
| 素材ライブラリのデータセット | 親の子の順序 |
| データセット内の素材 | そのデータセットの画像順序 |
| バンドル内の素材 | そのバンドルノードの素材順序 |
| キャンバス生成ノードの参照 | そのノードの接続順序 |
| 生成フォームの参照カード | 送信される参照の配列 |
| ディレクターバーのクリップ | タイムライン |
| 絵コンテビルダーのショット | ビルダーの選択 |

<Note>
  生成フォームでは、**同じメディア種別**の参照どうしでしか順序を入れ替えられません。
</Note>

## 名前変更、タグ、削除

名前は素材プレビューダイアログの上部か情報パネルでその場で変更します。タグも同じパネルで、入力して Enter を押します。

削除は素材メニュー、サイドバーのサムネイルのポップオーバー、アイデア詳細から行えます。1 件の削除には確認があり、複数選択の削除では何件消えるかが示されます。

## コメントといいね

どちらも素材プレビューダイアログにあり、ワークスペースが許可しているかどうかに従います。いいねにカーソルを合わせると、誰がいつ押したかが表示されます。[閲覧者のアクセス](/ja/workspaces/viewer-access)を参照してください。

## AI による説明

**画像を説明**、**動画を説明**、**音声を説明**は、AI が素材を読み取って文章の説明を返します。コピーできます。キャンバスでは同じ機能が結果からテキストノードを作ります。
