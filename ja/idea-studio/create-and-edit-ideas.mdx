## アイデアを追加する

入れたいフォルダを選び、左のツールバーで**アイデアを追加**をクリックします。

ダイアログでは**名前**と**タイプ**を尋ねられます。タイプは今いるフォルダから推測されるため、キャラクターフォルダで作ったアイデアは最初からキャラクターになります。

そこから 2 つの道があります。

<Tabs>
  <Tab title="クイック作成">
    **クイック作成**をオンにすると AI を完全に飛ばし、名前とタイプだけで保存できます。残りは後で埋めます。
  </Tab>
  <Tab title="AI で生成">
    参照するあらすじや脚本を選び、欲しいものを説明し、必要ならファイル（`.docx`、`.pdf`、`.txt`、`.md`、画像。ドラッグまたは貼り付け）を添えます。AI がアイデアの下書きを作ります。
  </Tab>
</Tabs>

## アイデアのフォーム

新規作成でも編集でも、フォームの項目は同じです。

| 項目 | 備考 |
|---|---|
| **選択中の画像** | どの添付画像をカバーにするか |
| **タイプ** | あらすじ、脚本、キャラクター、ロケーション、小道具、衣装、シーン、ショット、その他 — 自分で入力しても構いません |
| **タイトル** | |
| **概要** | **必須。** このアイデアが参照として使われるとき AI が読む部分です |
| **詳細な内容** | Markdown |
| **タグ** | 自由入力 |
| **画像プロンプト** | 下書きを作る **AI 生成**ボタンつき |
| **動画プロンプト** | 同上 |

<Tip>
  概要は、このプロジェクトを一度も見たことがない人に説明するつもりで書いてください。「60 代の背の高い漁師。風雨にさらされた顔、色あせた青いコートをいつも着ている」は、「その漁師」よりはるかに多くの手がかりをモデルに与えます。
</Tip>

## あとから編集する

アイデアを開き、詳細ビュー下部の**編集**を使います。現在の値が入った同じフォームが開きます。

削除も同じ場所の**削除**から行います。削除には確認があります。

## 複製する

ファイルツリーでアイデアを右クリックし、**コピー**を選びます。複製には「コピー」の接尾辞が付き、同じフォルダに置かれます。

システムフォルダは名前の変更・削除・コピーができません。中のアイデアだけが対象です。
