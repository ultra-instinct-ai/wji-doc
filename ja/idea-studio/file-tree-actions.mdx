左パネルのファイルツリーが整理の場所です。その真価は右クリックにあります。

## 一般的な操作

アイデアやフォルダを右クリックします。

| 操作 | 対象 | 備考 |
|---|---|---|
| **チャットに追加** | アイデア | アイデアをワークスペース AI チャットに文脈として送ります |
| **〈タイプ〉を追加** | フォルダ | 表記はフォルダに合わせて変わります（キャラクター内なら「キャラクターを追加」） |
| **新しいフォルダ** | フォルダ | サブフォルダを作ります |
| **コピー** | アイデア | 「コピー」の接尾辞つきで複製します |
| **名前を変更** | 両方 | |
| **削除** | 両方 | |
| **素材をダウンロード** | 両方 | フォルダ構造を保った ZIP |

6 つのシステムフォルダ（ストーリー、キャラクター、ロケーション、小道具、ショット、その他）は名前の変更・削除・コピーができません。

<Note>
  ファイルツリーに検索ボックスはありません。フォルダとタグで見つけられる状態を保ってください。
</Note>

## AI ショートカット

ここが覚えておく価値のある部分です。アイデアを右クリックすると、その**タイプ**に応じた AI 操作が表示されます。

<Tabs>
  <Tab title="あらすじ・脚本">
    - **すべてのキャラクターを要約**
    - **すべてのロケーションを要約**
    - **すべての小道具を要約**
    - **絵コンテを生成**

    いずれも文書全体を読み、対応する一式のアイデアを一度に作ります。
  </Tab>
  <Tab title="シーン">
    - **すべてのロケーションを要約**
    - **絵コンテを生成**
  </Tab>
</Tabs>

これらはいずれも Build with AI を開き、出力があらかじめ選ばれ、右クリックしたアイデアが参照に設定された状態になります。保存前の確認は通常どおり行えます。

<Tip>
  新しいプロジェクトを始めるとき、たいていこれが最速です。脚本をストーリーのアイデアに貼り付け、右クリックしてキャラクター・ロケーション・小道具を 3 回に分けて要約します。数分で中身の詰まったワークスペースができます。
</Tip>

## ダウンロード

**素材をダウンロード**は、選択したノードの下にあるすべての画像と動画をフォルダ構造を保ったまま ZIP にまとめます。フォルダに対して行えばその配下すべて、単一のアイデアに対して行えばそのアイデアの添付だけが対象です。
